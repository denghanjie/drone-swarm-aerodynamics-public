# Source privacy review

The new package contains synthetic simulation configuration, code, protocols, local historical-result references and previously verified public research citations. No personal correspondence, user attachments, private environment paths or credentials are intentionally included. Runtime binaries and private browser profiles are not copied into the repository.

Before source freeze, scan every new text file for private home/temp paths, private-key headers and common token formats; reject any match. The freeze helper also checks inherited pinned-file identities and complete relative source dependencies. This is a scoped review, not a universal secret-detection guarantee. The result and captured screenshots require separate privacy review before public result publication.
