# Physical source-contract planning, not an experiment

The model currently emits an isolated-hover wake even when the modeled motor command changes. That assumption must be tested before we can interpret a coupled swarm as physically predictive. The proposed next question is whether a measured single-drone wake can be rescaled using independently measured thrust, including a deliberately unequal motor condition.

[EVIDENCE-AND-NEXT-TEST.md](EVIDENCE-AND-NEXT-TEST.md) separates verified published findings, our hypothesis and missing measurements. The newly verified article is Wolf et al. (2024), DOI [10.1007/s00348-024-03880-3](https://doi.org/10.1007/s00348-024-03880-3). It supports investigating a restricted steady scaling law; it does not validate our 27 g drone model. Bibliographic additions are in [additions.bib](additions.bib); inherited references retain their original ledgers.

This is a separately labeled planning record. No physical observations, digitized fields, calibration, numerical scientific output or validation score were generated. No experiment is allocated here, and no prior campaign's frozen rationale is amended. The exact public memo/bibliography bytes and editorial transformation provenance are preserved. Current retrieved data do not supply the independent load, flow, actuator and uncertainty evidence required to execute the proposed test.

The runtime replication remains a different, numerical question: can a browser calculation reproduce this assumed model within fixed output tolerances? Numerical agreement cannot answer the physical source-contract question.
