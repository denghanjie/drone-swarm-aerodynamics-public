WHAT WE TESTED

Can fewer digits still give useful numbers?

The GPU uses binary32 arithmetic, which keeps fewer digits than the binary64 CPU reference. We fed it saved incoming-air speeds and compared every returned rotor force with an independent reference.

We separated errors from packing the inputs, dividing them, solving the equation and multiplying the final force. Passing this component does not establish a GPU speed advantage or validate the model against real rotors.

AN IMPORTANT LIMIT

A stopping rule is not an accuracy test.

Of 21,631 positive inputs, 21,630 used all 12 permitted Newton updates. The results still passed the independent accuracy checks. One positive input met the strict step threshold; 2,401 zero inputs needed no update.

We retained only final values, so we cannot tell from these records whether the iterates oscillated, stagnated or behaved otherwise. We have not tuned the threshold or measured its speed cost.
