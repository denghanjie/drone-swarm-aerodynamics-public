# Fixed controls and saved-evidence contract

This is prospective source only. The inherited fixture functions are invoked only inside the new authorized producer allocation. Exactly 102 direct screen builds and 62 complete native queries are permitted. There are no additional direct solves, preflights, retries or tuning calls.

The first 96 builds traverse the 48 pinned inherited fixtures in their declared order, F then C, each with fresh caller-owned arrays. Preserve all kernel return fields except top-level phasesMs in `output`; preserve phasesMs separately. Every Number becomes its 16-digit binary64 word, including nonfinite values and signed zero. Typed arrays preserve their constructor name and all values. Ordinary arrays remain arrays; object keys are sorted. `states` is included in the full output, though its intentional reference to caller states is excluded from the returned-storage ownership check. No diagnostics or work fields are excluded.

Retain both planes-66 outputs. The remaining six builds are sparse2 F/C, planes62 F/C, fallback258 F/C, with the original fixed definitions. After each pair, save both retained output and input snapshots again and require exact equality. All selected returned arrays/typed-array buffers have fresh object identity across calls, are disjoint from caller arrays, and typed arrays own complete buffer ranges. The evidence records path, kind, identity, buffer identity and byte ranges, with the cumulative prior identity set. These identity observations are producer evidence, independently consistency-checked by the auditor, not something an offline auditor can reobserve.

The next 48 queries traverse the 24 pinned native-wrapper fixtures, F then C. All inherited expected statuses and analytic checks remain. The runner saves complete encoded native evidence, including timing, and compares the two outputs after excluding ONLY timing and diagnostics.buildPhasesMs. Inputs use a descriptor-value snapshot: Numbers become `{number:word}`, objects become `{array:boolean,properties:[[ownKey,snapshot],...]}`. This retains array length, literal holes, signed zero, NaN and Infinity. Only ordinary literal data properties are supported.

For each arm separately, the final seven queries are A, B, C, A-repeat, guard1, guard6, A-clean. F runs seven then C runs seven. A has stable IDs 1,2,3, upright quaternion, zero velocities, and positions [0,0,0], [0,0,.6], [0,0,1.2]. The rotor rows are:

B doubles only middle rotor0 and reverses the caller drone order. C swaps middle rotor0/rotor1, preserving the exact total. Separate coefficient witnesses require B first-receiver rotor0 from middle source to increase, B middle-receiver rotor0 from top source to decrease, C source coefficient to remain exact, and C middle-receiver rotor0 coefficient to decrease. Thus a uniform force scaling cannot conceal a coupled beta/nu error. A-repeat and A-clean require strict semantic equality with A. Both first A outputs remain retained and are reencoded after every later call, without changed words or storage reuse. Full F/C pairing covers all seven steps.

Each wrapper guard first invokes the allocation guard and then increments its local ordinal. It throws at poll1 or poll6. The wrapper must return resource-failure/cooperative-guard at stage input/build respectively with the exact ordinal. Poll6 occurs at the second kernel receiver after first-receiver work may have initialized beta. This is a cancellation lifetime check, not a concurrent or hostile callback claim. The actual two-million-positive-term capacity guard is preserved by static review only; no oversized synthetic fixture is run.

`controls-partial.jsonl` is an append-only record journal, written before each assertion. Kinds are kernel, native, pair, kernel-retention, native-retention and analytic-witness. Full records include inputs, complete outputs, expectations, individual checks and ownership identities. A failure stops the producer with the journal intact. `controls.json` is written only at complete pass; it contains the same records grouped into kernel/native/pairChecks/kernelRetention/nativeRetention/analyticWitnesses, plus schema, counts and passed. The auditor checks journal records against this final object in the exact schedule, recomputes complete pair comparisons and analytics from saved words, and validates ownership and retention evidence without invoking a numerical module.

Controls runner and saved-evidence auditor have the same author. Their independence is from candidate/producer scientific implementation, not from each other. A separate source reviewer challenges both. These finite controls do not prove universal equivalence, identical allocation failure behavior, portability or physical validity.
