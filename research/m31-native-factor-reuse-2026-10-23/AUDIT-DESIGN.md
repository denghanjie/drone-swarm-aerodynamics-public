This is a prospective source artifact. No model, fixture, replay, benchmark, numerical preflight, reaggregation or UI allocation was run while preparing these files. Only source inspection, metadata-schema inspection, Python AST parsing and JavaScript syntax checking are permitted before the parent completes review, exact freeze, public publication and independent public source identity verification.

## Independence and bounded scope

`source/audit.py` imports the Python standard library and `common.py` only. The common module supplies source/public gates, bounded input identity reads, output accounting and closure infrastructure. It does not supply scientific normalization, control fixtures, timing arithmetic or CSR reconstruction. The auditor never imports the producer, candidate, native baseline, kernel, original fixture modules, previous auditors or browser. It performs zero native calls, zero direct kernel builds and no square-root/norm/force/solver/trajectory calculation.

Controls runner and auditor have the same author, which is disclosed rather than represented as two independent implementations. The auditor independently writes the literal fixture construction, descriptor snapshots, whole-output normalization, analytic assertions, storage-evidence consistency checks and exact journal schedule in Python. A separate protocol challenger reviews both source files. Identity/provenance and scheduling architecture was adapted as source text from the earlier radial-integration and phase-attribution auditors; no previous auditor is executed or imported.

One saved-only allocation is allowed: 1800 seconds and 128 MiB of output. It starts only after the producer is closed with a successful supervisor. A failure is retained with its exception, checked file pins and read events; it does not authorize repair, retry or new measurements. The final report must have passed=true, calls=34560, stages=1920 and nativeCalls=0 before finalization may proceed.
