# Causal airflow prediction: a bounded promising result

One 0.1 s, two-seed numerical screen reduced all four trajectory-error maxima by 26.5–54.1 times versus zero-order holding, at the same scheduled field count. All 14 arms and 19 predeclared gates completed. This is a useful mechanism result, not physical validation, measured speedup, novelty or permission for another run.

## Provenance and exclusions

Code files are exact as-executed source records, including original relative archival names. This is not a standalone runtime bundle: private release/admission records and compatibility input are excluded, and dependencies are identified in SOURCE-MAP.json. No private R8 archive was recovered or used.

The public summary omits runtime/retention metadata. Run-record editions omit nearest-margin witness locations while preserving extrema, counts and other scientific values. The independent-review edition removes one RSS observation and fixes spacing. Reports identify original evidence hashes; EXPORT-MANIFEST.json records every transformation. Inventories, host logs, raw binaries, original paper figures and the shared vendor blob are not duplicated. Three.js is reused from the existing public support-factorial viewer.
