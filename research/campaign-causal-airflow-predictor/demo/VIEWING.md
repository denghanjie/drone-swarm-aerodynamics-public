# Saved-data viewer

Serve the repository with an existing static HTTP server and open this directory. The viewer reuses the shared public support-factorial Three.js module. No vendor download or installation is required.

Only 352 exact saved reference poses animate: 11 times x 16 vehicles x 2 seeds. Six comparisons expose 30 paired full-state witnesses. They are isolated states, never reconstructed predictor/ZOH trajectories. Playback is ten times slower, without interpolation.

Static syntax, links, DOM identifiers, source hashes and data projections are checked. Browser rendering remains unverified. No browser launch/retry was attempted here following the earlier process-singleton socket denial. Read the numeric table, report and JSON if WebGL is unavailable.
