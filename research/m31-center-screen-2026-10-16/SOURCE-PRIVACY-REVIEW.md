# Source publication privacy and dependency review

This package contains authored research code, prospective methodology, static review notes, source metadata and inherited public simulation code. It contains no original paper assets, attachments, chat transcripts, credentials or private executable paths. Runtime records contain binary hashes/version/architecture only. Process records deliberately withhold private exception paths and PIDs. Final logs and generated artifacts require their own prepublication review.

Scientific imports are closed over the package's kernel, lean anchor, anchor kernel, reference excerpt, controls and independent numeric reference, plus the unchanged public M31 simulation, factory-wide, factory, geometry, grid, wall-filter and step02c physics modules. Standard-library/runtime dependencies are identified in runtime.json; NumPy RECORD identity is metadata identity, not an independent hash of every installed package file. The manifest enumerates each imported research source. No candidate or scientific module was imported during preparation; syntax parsing does not evaluate its functions.

Viewer drafts are display code, outside the scientific source manifest and one-shot allocations. They may be completed only against terminal artifacts and receive separate UI checks. No replay itself qualifies scientific claims.

The corrected final-payload limit checks and independent saved-review schemas require final static clearance, then source publication and independent remote manifest verification before launch. This review does not assert a general runtime-equivalence theorem, physical validity, novelty or a passing result.
