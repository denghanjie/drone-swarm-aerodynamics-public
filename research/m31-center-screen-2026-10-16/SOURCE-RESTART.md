## Exact invocation interface

Use the pinned Python executable as `PYTHON` and the pinned Node executable as `NODE`; resolve them locally without saving private paths in public logs. With this package as working directory, the authorized launches are:

```sh
"$PYTHON" source/run.py candidate "$NODE" VERIFIED_MANIFEST_SHA SOURCE_COMMIT
"$PYTHON" source/run.py review "$PYTHON" VERIFIED_MANIFEST_SHA SOURCE_COMMIT
"$PYTHON" source/seal.py VERIFIED_MANIFEST_SHA SOURCE_COMMIT
```

The placeholders must be replaced from the independent publication receipt, never guessed. Both supervisor invocations require HEAD to remain exactly SOURCE_COMMIT. Save the source receipt without advancing HEAD until both launches close. The review requires actual candidate closure. The metadata seal requires both terminal records and is also exclusive. This document supplies a procedure, not evidence that any invocation succeeded.
