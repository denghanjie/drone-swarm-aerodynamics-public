# Frozen cost-record interface

All paths in source-manifest are relative to repository root. Source/dependency pins are verified against local and committed bytes before invocation. The four inputs and original complete reference results remain in the preceding swarm-transfer package. No target calculation has occurred in this new package before source publication.

`results/evidence.json` contains complete=true only after 21 controls, eight qualifications, 84 full-query calls and 56 cached calls. An interrupted invocation writes failure.json and partial-evidence.json when possible; already saved control/qualification/call files remain authoritative for the completed prefix.

Controls: IDs and exact position token strings are in source/experiment.cjs and retained in every control JSON. Identity xyzw quaternion, hover nominal forces, all other state entries zero. Both builders execute once, no solve. Store complete symbols, CSR, admission/graph and work. Grid flag must match expectedGrid. Nonfinite metadata are JSON null; positionTokens preserve NaN, Infinity and signed zero explicitly. Negative/overflow invalid guards remain meaningful failures of model admission, not experiment failure. All/grid agreement is required.

Qualification: for each input in index order, all then grid, each with O then P and residual; 8 builds, 16 solves. Save BOTH full diagnostic bundles, not only assertions. Each `ID-LABEL.json` holds input census, admission, full graph, symbol census, certificate, exact work, L bound, solution objects O/P, array artifact pins and fingerprints. Symbols are gzip uint8 [receiver,source,rotor]; offsets uint32LE [4N+1], sources uint32LE [M], K and a float64LE [M]. Solutions retain y, four `{alpha,x,T}` objects per drone, generating work, separate residualMap/work/log/mismatch, plus P iterates/iterations/converged/lastChange. The original reference schema is unchanged. Qualification comparisons check exact symbols, offsets, sources, input/admission/graph/counts/L/geometry decisions; K tolerance 2e-12 absolute + 2e-12 relative; all solution values including alpha within 1e-9 relative; exact counters/termination; log residual <=1e-9 and normalized mismatch <=2e-9. Rejected target or failure stops before timing. Tiny controls may reject their model domain.

Timed call raw record is persisted before validation in call-NNN-raw.json. It includes sequential index, workload `full` or `cached`, id, method A/B/C or O/P, block -1 for warmup or 0..5, warmup boolean, uninterrupted totalMs, disjoint phasesMs, timed checksum, geometryWork, certificate, solve and residual work, iterations, residualLog/mismatch. Completed call-NNN.json adds its raw pin and validation. The clock excludes raw-record writes, full comparisons and cryptographic hashes. All durations retained. No forced GC.

Full phases: input census/geometry; index certificate+build; geometry candidate queries/sort/exact terms/sparse assembly; admission plus coefficient scaling; method-required setup (order only A/B); solve; residual; small checksum; remainder. Remainder includes returns and boundary overhead; phases sum to total by construction. The A path neither builds a grid nor scans an extra box nor materializes an N-element source-ID list for every receiver; it uses the same direct integer j loop on an unindexed path. The C path does not build an unused ordered schedule. Depth is qualification only. All methods include receiver-level resource checks. Cached phases solve/residual/checksum exclude immutable matrix preparation; fresh initial y/scratch every time.

Timed checksum is `sum_i[y_i*(i+1)+sum_r(T_ir)] + firstK + lastK` with empty K endpoints zero. Full SHA is outside clock. Matrix SHA256: concatenation of exact little-endian offsets, sources, K, a bytes, then UTF8 JSON.stringify object in order `{input,admission,graph,symbolCounts,ordinaryLmax}`. graph here excludes qualification-only order/depth. Solution SHA256: UTF8 JSON.stringify in order `{values,work,residualWork,residualLog,sourceReceiverMismatch,iterations,converged,lastChange}`; absent O fields default1,true,null. `values`: y, then rotor-major alpha/x/T in vehicle order, then residualMap.y, then residual alpha/x/T. No timing fields or P trace in fingerprints. Every transient array is numerically compared outside clock against its qualified output; full/cached records retain comparison maxima and first failing scalar, hashes and counters. Exact repeat matrix and solution hashes required per solver. Large timed arrays are not persisted each repeat: saved-record review can inspect qualification arrays and these assertions, but hashes do not independently reconstruct transient arrays.

Order: cases fixed [n1000-t20,n5000-t20,n5000-t60,n5000-t180]. Full warmups case order × ABC. Measured blocks b=0..5 rotate case order by b modulo4; for original case index c use permutation (b+c)%6 from [ABC,BCA,CAB,CBA,ACB,BAC]. After all full calls, cached warmups case order × OP. Cached measured blocks rotate cases identically; OP at even b, PO at odd b. Exactly 140 calls; warmups saved and excluded from reported summaries.

One-time input read/decode and reference loading times are separate. Diagnostic qualification computation includes tensors/traces; compression and buffered I/O/hashing/serialization are separately timed and not fsync latency. Cache reuses qualified grid objects and schedule; validationMs and known typed CSR bytes are recorded, JS object overhead explicitly unmeasured. The full decoded states, geometry, graph and comparison solutions remain resident. Memory environment includes actual RSS rather than pretending typed array bytes are total memory.

Saved-record reviewer must read source/dependency pins, controls, all eight bundle arrays, original refs and 140 raw/validated calls. It may compute differences and summaries, but MUST NOT run geometry, root solves or new timings. The review is independent of kernel implementation; earlier Python/NumPy review remains the numerical oracle provenance. A timing usefulness failure does not imply review failure.

Postclock repeat validation also compares certificate and timed checksum with qualified expectations. Qualification retains and compares all P iterates and exact lastChange. Raw calls explicitly include converged/lastChange; complete=true is guarded by the exact planned identity sequence. A failed output write retains compact current timing context where the failure reserve permits. NODE_OPTIONS must be empty and the Node argument list contains no execution flags.
