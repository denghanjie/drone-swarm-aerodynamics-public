# Result publication privacy review

New records contain synthetic identifiers, numerical protocol metadata and a PermissionError class; no private paths, stack traces, serials, hostnames, usernames, credentials or environment dumps were captured. Candidate stdout/stderr are empty. Saved-review errors use repository/package-relative tokens. GitHub owner/repository and public commit identities are deliberately public research provenance.

Viewer display.json is a deterministic subset of previously published records: ID,N,time and final amplitude y. Its provenance pins point to the exact original public case JSON; actual17-value pose inputs are fetched from the earlier package and hashed. No new physical/simulation data is fabricated. No raw private image or user attachment is published.

Source and scientific records are unchanged. The launch-stage uncertainty is disclosed; missing evidence is not converted to a zero-speed value. Text scans/manual inspection apply to new report, review, viewer and QA files before publication. Screenshots, if retained, show only the local research page, not unrelated browser chrome or desktop content. No data redaction changes scientific values.
