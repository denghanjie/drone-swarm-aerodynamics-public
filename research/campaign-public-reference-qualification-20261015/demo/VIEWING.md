# Saved-data evidence viewer

Serve the repository as static HTTP and open this directory. The app uses the existing shared Three.js module at the relative path in app.js. No vendor is duplicated.

The 352 reference poses are exact position/quaternion projections of saved full states. Only the two finest-joint references animate, using eleven discrete frames each at 10x slower than recorded time. Fifty isolated paired maximum-error witnesses retain full17 states. There is no held-flight animation or interpolation.

Static syntax, DOM identifiers, data shapes/finiteness, source hashes and conversion are checked. Browser rendering remains unverified: the installed local browser could not create its required process socket before loading the page. No screenshot exists and no security-bypass option was used.
