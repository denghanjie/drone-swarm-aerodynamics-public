# Public checkpoint review

All22 frozen file hashes remain unchanged. Raw snapshot binary/receiver hashes match the scientific result. All50raw files are retained; no raw values or source arithmetic were transformed. The public payload contains simulation code, synthetic drone states, research outputs and verified bibliographic references. No private attachments, credentials, account cookies, private workspace files or contact details are included.

Six postrun review/QA documents contained machine-local paths. Their public copies replace only the repository path with `<REPOSITORY_ROOT>` and the machine-specific Playwright module path with `playwright`. The exact original files remain in the local /tmp review/launch archives and private publication records; original and transformed SHA256s are recorded in results/public-transformations.json. The directories named *-public contain these disclosure copies, not a claim of byte-identical originals. Scientific hashes, numerical outcomes, timings, failure history and checker executable logic are unchanged. Runtime argument arrays in public copies contain a placeholder and are provenance displays, not directly runnable commands.

Screenshots were visually inspected. Viewer QA covered12snapshots and selected evidence values, desktop/mobile controls and corruption handling; visual legend/arrow fixes were rechecked. QA scratch screenshots were overwritten during display correction, not scientific evidence. Direct canvas selection is not claimed as automatically tested. Local-path and common-secret-pattern scans passed; this is a scoped review, not proof of absence of all possible sensitive strings.

The final manifest records every checkpoint file except itself. Publication verification must independently fetch the result commit and exact manifest bytes; that verifies published metadata, not an independent redownload of every large binary. Older microcheck archive transfer failures remain documented separately.
