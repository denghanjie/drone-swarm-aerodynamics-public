[Python replace](https://docs.python.org/3/library/os.html#os.replace), [Node renameSync](https://nodejs.org/api/fs.html#fsrenamesyncoldpath-newpath), [Linux rename](https://man7.org/linux/man-pages/man2/rename.2.html).

All 21 prescribed decisions matched. This supports only the fixed-interleaving infrastructure claim; integration, arbitrary concurrency and crash durability remain untested.
