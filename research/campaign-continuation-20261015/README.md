## Reproducibility boundary

Plans and executed scientific scripts are archived byte-for-byte, including their historical prospective status text, original paths and hash checks. Later adoption/completion is recorded in the reports and outcome receipt. Those scripts expect their original execution layout, source hashes, approval files and, for extraction, the separately obtained original figure. This public selection is therefore not a turnkey rerun package, and no runtime receipt or raster has been fabricated to make it one. Public-edition viewer imports and report links use the current repository layout. A new run requires a separately declared setup; these immutable outputs should not be overwritten.
