# Event-only diagnosis publication scope

These files are newly written, selected summaries of the already-retained AUDIT-C1-R3 anchor failure. They preserve the terminal failure and publish only event counts, tick/time mapping, comparison conclusions and four relevant signature values. They contain no retained-file inventory, source-pin table, runtime manifest, raw state array or decoded object graph.

Detailed retained-file and runtime inventory publication was blocked and explicit approval remains pending. These summaries do not reproduce or re-encode that inventory. The original diagnosis, failed evidence and earlier publication proposal remain unchanged and local. No publication, retry, gate, benchmark or scientific execution is authorized by these files.

The accompanying two code files explain the selector and comparison order. They do not constitute the complete frozen scientific bundle. The public results checkpoint is intentionally incomplete for reproduction, and omission of private evidence must not be presented as a passing gate.
