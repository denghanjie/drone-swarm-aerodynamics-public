Necula checks individual compiler transformations rather than assuming optimizer correctness (abstract and section 1, PDF pp. 1–2). We draw inspiration for separate candidate/baseline and baseline/record checks; our finite test corpus is not his symbolic translation-validation method. [Verified institutional full text](https://people.eecs.berkeley.edu/~necula/Papers/tv_pldi00.pdf).

Sargent distinguishes data validity, computerized-model verification and operational validity, and calls for detailed and summary test documentation (sections 3.1, 4 and 8). We use that distinction to classify the mixed-clock failure as a record-selection problem; correcting it would not validate drone physics. [Official proceedings tutorial](https://informs-sim.org/wsc20papers/002.pdf).

Our proposed next test is an explicit source-event identity contract: source hash, source tick duration, source tick, physical time, current tick and anchor row must agree. Test all saved-state selectors plus deliberately wrong units and missing metadata before another numerical release. This is our proposed adaptation, not a finding attributed to either source, and it has not been run.
