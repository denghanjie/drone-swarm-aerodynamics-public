# Source publication privacy review

The new package contains research code, explicit synthetic scenes, model/protocol text, reviewer records, source snapshots, runtime executable hashes and relative repository paths. No user chat, pasted attachment, private image, credential, physical participant data or downloaded paper asset is included. The research view reuses the repository's existing Three.js vendor assets.

A recursive source scan found no machine home/temp path, attachment reference, private-key marker or common credential token pattern. Runtime paths are provided via environment at execution and are not recorded in the public pins. Source supervision replaces repository, private run and runtime prefixes in public logs; raw logs remain private. Pattern scanning supplements content review and is not a proof against every possible secret format.

Publication is authorized to the existing public research repository/branch. The exact source manifest and public commit must be independently verified before numerical evaluation. Display drafts are excluded from the scientific source manifest and will receive separate result/display evidence pins after completion.
