# Source publication review

This package consumes existing public synthetic states and numerical references. New files contain source, protocols and source-only technical reviews. No user attachment, private conversation, credential, unrelated personal data, physical dataset, hostname or serial number is included. Runtime identification uses a hash and byte count, with no installation path. The localhost preview remains local.

The runner sanitizes repository/runtime directories in saved exception messages. This does not alter any scientific value. Private scratch memo names under /tmp are administrative provenance only. Before push the parent performs a bounded scan for home/temp personal paths, private-key headers and common token formats, and verifies all immutable source/data pins. It is not a universal secret-recognition guarantee. No new license or redistribution claim is introduced; reused Three.js notices remain.
