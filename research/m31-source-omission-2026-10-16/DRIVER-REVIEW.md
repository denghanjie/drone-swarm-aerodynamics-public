## Resolved pre-exposure findings

1. **Timing bookkeeping.** The first candidate version disabled masks, omission lists and receiver decision records with `evidence=false`, making timing exclude promised omission bookkeeping. Current C allocates/fills these structures in all calls, including measured calls; only serialization/persistence is disabled. M shares geometry/traversal/load assembly while disabling bound-specific preprocessing/work; this is an appropriate matched implementation comparator.
2. **Completed-output preservation.** Initially, B/M/C outputs were written only after I completed; an oracle failure could discard complete returned queries. Each successful B/M/C query is now saved before the next method. The binary is written before scalar receiver validation, preserving the output if that validation fails.
3. **Failing source-bound witness.** The I callback now records the receiver state, candidate row/decision, complete independent term vector and code vector before checking source bounds/zero classes/aggregate omission. The witness is cleared only after the completed audit row has been appended. This preserves the current receiver on a failed assertion, without another oracle pass.
4. **Historical manifest pin.** The configured prior-reference manifest digest is now explicitly checked. All consumed prior files must additionally be directly included in the new freeze; hashing only the manifest does not hash the files it names.
5. **Raw/published result consistency.** The final result now snapshots `files.slice()`. This prevents writing raw/result.json from mutating the published object's file inventory via a shared array. The result does not include its own hash; an outer postrun manifest can do so without a self-hash cycle.
6. **Complete bisection gate.** The I callback now checks finite solution scalars and endpoints, ordered endpoints in [0,1] containing x, width <=2e-15, and integer iterations in [0,96], in addition to the residual. This restores the complete inherited bracket diagnostic.
7. **Complete matrix assertion.** The terminal path now requires 38 completed case results, 152 attempted field queries and 36 timing-query records.
8. **Timed failure witness.** Full-output comparison failures now preserve observed/reference scalars and both complete 17-value rows; checksum failures preserve actual/expected checksums. This closes the lost-sign/value gap when a measured query fails before its timing record is appended. Successful timing repeats retain checksums/counters/times and the runtime passing comparison, not duplicate output matrices; the offline review must retain that evidence limitation.
9. **Consumed domain-vector identity.** Historical inflated vectors now also verify receiver ID and both prior code hashes as well as exact length. Source-commit provenance is required to be a 40-hex string before creating the started record; the coordinator must supply the actual verified source commit.

## Oracle and source-omission audit

For each fresh/fixture input, the prescribed order is B, M, C and I. I calls its independent direct field exactly once; each receiver callback exposes `terms[4*source+rotor]`, complete codes, ordinary winds and local work metadata. The driver selects positive-omission terms from that same callback, checks every bounded-zero source's four terms for exact zero, checks each positive omitted term against its stored source bound plus the fixed audit allowance, and reconciles the four omitted-term sums with full-minus-candidate inflows. It then calls the independent receiver solver exactly four times for that receiver. Neither the callback nor the verification helpers rerun a field or solve a root a second time.

The candidate uses ascending grid source IDs; retained accumulation order for each receiving rotor stays ascending. Source-first traversal may report a different first invalid tuple than the original rotor-first path. The protocol correctly claims domain-reject agreement rather than exact first-offender identity. Both candidate methods throw the production `DomainError`, while I uses its own class; the driver distinguishes and records both. Expected rejecting fixtures continue through the four prescribed methods for domain agreement. A valid-case, unexpected-domain or numerical failure cannot enter timing.

The source-bound branch order checks ambiguous near-domain obligations before projection/radial omission. Fallthrough from a near-domain fallback retains all four rotor evaluations. No prior domain pass or reference field is supplied to C. The empirical numerical margin is explicitly weaker than a universal interval certificate. Body thrust and signed roll/pitch budgets are acceptance quantities; world-vector errors are descriptive. Nominal yaw is fixed to zero in all load assemblies.

For the twelve exposed inputs, only C is newly evaluated. The driver selects the retained independent force-reference columns correctly: rotor inflow column 1, thrust column 4, and vehicle total/moments/world-force/world-moment columns 1,5,6,11–13,25–27. Full source magnitudes are absent historically, so those cases have aggregate omission/load checks and prior-code support checks, not fresh per-source magnitude proof. The no-code-7 historical rule is conservative: it may reject a claim whose realized rounded term happened to be zero, but it does not accept a known positive-support class as proved zero. That limitation is disclosed prospectively.

## Storage, schema and failure semantics

The 17-double output row maps correctly to four inflows, four effective thrusts, total body thrust, roll, pitch, three world-force components and three world-moment components. Generated-state rows have the separate documented 17-state layout. Complete generated poses are saved before field evaluation. Candidate two-bit masks preserve source identity, ascending positive-bound lists preserve source/bound correspondence, and source-audit rows retain all four independent terms for each positive omission plus root diagnostics and the independent output row.

Raw write guards reserve 4 MiB of the 128 MiB cap and stop instead of dropping scientific rows. The full required JSON/term overhead cannot be guaranteed to fit before execution; the protocol properly treats exhaustion as terminal. A completed result requires all requested inputs and measured passes. Partial streams remain on disk on failure; a later manifest must inventory them even when `closeStream` was not reached. The source audit stores only a digest for the full successful code vector and zero-inspection counts, not all exact-zero term doubles; the finite runtime checks and retained selected terms should not be overstated as a complete offline per-source reconstruction.

The one-shot supervisor provides a lock, repeated-ID/active/terminal/failure-ledger protection, cumulative 300-second allowance, process-group termination/reaping, raw-byte monitoring and CPU/RSS diagnostics. The unchanged full B field has no inserted inner guard; M/C and I have cooperative boundaries plus the common outer watchdog. An interrupted full field can lack current output values; the protocol accurately limits retention to available context and earlier completed evidence. Preflight errors before the driver's try block are preserved by supervisor logs/budget rather than guaranteed raw failure JSON.

## Cost study and case-scope limits

The six frozen B/M/C permutations produce one discarded warmup and five measured complete queries per method and fresh input. Timed queries rebuild geometry, grid, neighbors, bounds, masks, retained fields, roots and loads, and compute their output checksum. They do not reuse correctness masks or fields. Serialization and persistence are absent from measured query bodies. The driver checks each timed output against its same-method correctness output and checksum. The correctness-call wall values include evidence callbacks and must not be pooled with the dedicated timing records. Report medians, ranges and C/B and C/M from the retained five measured passes, without confidence intervals or a physical real-time claim.

M/C include per-receiver cooperative guards while B uses the original field and watchdog; this instrumentation difference is explicitly disclosed. An observed C/B gain alone cannot identify omission as its cause; C/M is necessary. Bound preprocessing is paid by C and disabled for M, avoiding an artificial matched baseline that pays unused bound cost.

The final protocol supersedes the proposal's 16-fixture/120-query sketch with 24 actual fixtures and 152 attempts. It also explicitly narrows multiple-weak/signed-moment constructions to observed mechanisms, without guaranteeing that they exhaust capacity or produce a particular omission pattern. Scalar nextUp/capacity checks exercise acceptance arithmetic; they do not establish that a spatial configuration reaches a bound threshold. The fresh lattices are fixed synthetic cases whose extent grows with N, not samples from a physical swarm population. No implementation result has yet been observed by this reviewer.
