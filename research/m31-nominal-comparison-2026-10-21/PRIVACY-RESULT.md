# Result privacy review

Retained data are generated simulation states, commands, nominal forces, derivatives, synthetic seed IDs, hashes and audit records. The complete44part journal schema contains no user attachments or credentials. Source and result text are scanned for private absolute home/temp paths, private-key headers and common access-token patterns. Parent inspected desktop/mobile captures: no unrelated private content was visible. Browser-owned process IDs and runtime versions are diagnostic metadata. These checks are scoped, not a universal secret-detection guarantee.
