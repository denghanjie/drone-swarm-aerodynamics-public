## 4. Exact-output contract

The oracle is the unedited frozen module, not a rewritten “equivalent” implementation. Load it with the same frozen aerodynamic dependency and a reviewed I/O redirection adapter. The adapter changes only physical output destinations into the isolated study tree; logical IDs/relative paths, raw Float64 encoding, JSON nonfinite encoding, SHA256, append/flush/atomic-write behavior and method call order remain identical. Both implementations receive fresh identical input values and the same logical ID. Verify that no write can target the old implementation root. The frozen oracle bytes and the adapter are separately hashed. Any adapter with unresolved semantic differences blocks execution.

Compare recursive values with exact numeric equality that distinguishes +0 from -0 (`Object.is` or equivalent); compare property existence and insertion order, arrays/lengths, Buffer contents, scalar types, and relevant reference-alias relationships. Compare encoded Float64 bytes and serialized artifact bytes directly as well as recording hashes. A hash alone is not the equality test. Error stacks and absolute sandbox pathnames are environment-specific and are excluded; constructor/type, message, enumerable detail, `auditLocation` and its absence, first failing input/pair, and partial class-state/counter changes must match. No tolerance or decimal rounding is allowed.

Mandatory invariants:
- Every ordered receiver, rotor, source combination excluding self is visited in receiver-major/rotor-major/source-major order, including inactive/out-of-neighbor-support pairs. Each has all eight signed margins. The nine category names/order and tilt margin are unchanged.
- Bit 0 is `downstream > 0`; bits 1–7 are the corresponding signed margin `>= 0`; tilt bytes use `>= 0`. Exact UInt16LE pair bytes followed by one tilt byte per drone and all rolling signature-stream bytes remain unchanged.
- Nearest uses strict smaller absolute margin; signed minimum/maximum use strict comparisons. Equal values retain the first encountered identity and its original signed zero. Run extrema also retain the first encountered observation on ties. No sorting or secondary tie-breaker is added.
- `compare` retains signature-change counting, pair/category traversal, first insertion ordering of its category Map, and strict greater-severity selection. Equal severity retains the earlier pair/earlier worst bracket. Preserve first/worst whole-swarm geometry and raw references, locations, offset order and byte hashes. Current tilt-only signature changes increment the signature-change counter without producing a pair-category tilt bracket; preserve and disclose that behavior rather than silently “fixing” it.
- Jump risk retains the inclusive downstream range and half-open radial-annulus conditions. Endpoint-only versus full-trial flags, repeated half-time stage identities, sample ordering, every flagged pair, counters and exact exception evidence must match. Stage order is an audit schedule, not ordered physical observations.
- `M.prepare` validation and first-error ordering are unchanged. Near-wake rejection retains `distance < neighborRadius && down > 0 && down < farStart && radial < nearFieldRadius`, in the original pair traversal, with the original class/detail and `auditLocation` attachment. A guard failure occurs before `observe` increments counters if that is what the reference does.
- Inputs, locations, raw states and previously returned samples may not be mutated by either variant. Returned `states`/`location` references and `raw || states` behavior are preserved. No distance/result cache survives into a later observation or aliases an older retained bracket.
- Empty/invalid input behavior and valid N=1 behavior are oracle contracts. Do not opportunistically change the reference's null-category/undefined-margin representation for N=1. This study's genuine retained workload remains N=16.
- `persist=false`, signature buffering/flush boundary 1024, final flush, zero observations, and one-shot finish behavior are tested. Full persisted bytes must agree with the same logical IDs. Failure cases are evidence, not silent skips.
