# Prepared sole saved-evidence review — unexecuted

This directory contains an independently written Python checker and one bounded
launcher. Neither has been imported or executed. Preparation has consisted of
reading the frozen review contract, source/schema and saved JSON reports, hashing
saved bytes, archiving the 53 source pins, and parsing Python syntax with `ast`.
No scientific binary arithmetic has been performed during preparation. The
parent reviewer owns the one permitted launch.

The exact command and checker arguments are preserved in `arguments.private.json`.
The public argument copy replaces absolute locations with explicit placeholders;
it is not represented as the executed argument file. The private index preserves
all exact original input paths. The public index removes paths while retaining
groups, stable labels, sizes, and original SHA256 values. Both sanitized files
disclose their transformations and bind the hash of the respective private file.

The input inventory has 53 frozen source pins, the freeze itself, 185 terminal raw
files, the original 5 science-result files, 2 separately classified postrun
publication/provenance files, and 4 private provenance/process receipts. The
original scientific budget remains the accounting record for its original five
files. The checker reconciles the complete results directory against both groups.
All 53 source files have preserved byte-for-byte copies in `source-archive`.

The checker covers:

- Source, freeze, every indexed file hash, complete raw inventory, the 184-entry
  embedded raw manifest plus its separately pinned result file, terminal result
  equality, source publication, exact invocation, runtime-pin and served-byte
  receipts.
- 60 literal control records and every one of their 18 numeric fields; six
  references containing 480,000 rows and 8,640,000 scalar fields; four GPU term
  streams containing 320,000 rows and 5,760,000 fields; three 16-row reductions.
- Identity, code, routing, stage mask, finite/range, raw positive-zero, scalar-term
  identity, count, exact stored-term addition and certificate checks. Reference
  and GPU payload validation uses saved fields; no norms, dots, profiles, fades,
  rotations or new geometry are computed.
- Exact dyadic R/Q/T/serial comparisons using integer units of 2^-1074 for f64 and
  2^-149 for f32. Stored display encodings are checked but never determine gates.
  Saved L1 negatives are counted separately from evidence-integrity failures.
- Deterministic seed/integer-draw provenance against the saved numerator/tick
  data; dyadic origin translation, f32 high/low packing, residual and reconstruction
  certificates; dependent nonposition copies, saved finite metric admissions,
  usefulness, stimulus and typed absence/candidate logic. Saved quaternion and
  angle values are never used to recompute rotations or norms.
- Three reference contrasts, two GPU vector contrasts, exact observed assessor
  counters/reservations, the dimensional driver-work counters, every saved GPU
  allocation/readback/release cost snapshot, device/campaign caps, and historical
  process-cleanup receipts. The driver's implementation-specific assertion ticker
  (`checks`) is retained in the pinned result, not independently reconstructed.

The full review has a 90-second external ceiling. Its child subprocess has at most
89 seconds including interpreter startup and all reads; the checker uses an
86-second cooperative deadline measured before any input reads. No model, GPU,
browser, shader or old-review process is launched. A permanent launcher lock is
created before preflight reads; the child creates its own permanent lock before
input reads. Any timeout, cap failure, identity failure or incomplete review is
terminal. No lock removal, retry or replacement review is permitted.

The 32 MiB output cap includes this file, both Python files, all 53 source archives,
private/public indices, private/public arguments, static preparation record,
prepared manifest, both locks, stdout/stderr logs, checker report and external
runtime closure. The launcher reserves 2 MiB within that total for failure closure,
keeps each log below 64 KiB, and limits child-created individual files to 1 MiB.
It inventories and sums the entire directory before launch, during monitoring,
and at closure, including the serialized closure's own size.

`runtime.json` will bind the exact checker, launcher, arguments and input-index
hashes, source commit and freeze SHA256, terminal science result/budget pins,
checker report hash, prepared-artifact identity before and after, elapsed times,
child exit/group closure, and complete output accounting. It is external evidence
and does not confer numerical qualification when the recorded comparison fails.

The reviewer should read `checker.py`, `launcher.py`, both exact private JSON files
and `prepared-manifest.json` before authorizing execution. No result is claimed by
this preparation document. Static syntax parsing is not a trial review.
