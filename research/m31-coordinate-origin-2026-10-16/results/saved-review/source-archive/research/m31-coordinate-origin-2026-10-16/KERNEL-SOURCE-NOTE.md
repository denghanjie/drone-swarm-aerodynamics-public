# Static source correspondence and preparation disclosure

The baseline is the published wake-slice `source/wake.wgsl`, SHA-256`ba780bc60e68bf66d29d3170c74abfd648568ddc835f7aebc7edee13dde2b108`, published within result checkpoint`3f8ce4b433c469c4a9a21b972206c287d48c6618`. The accepted local sources are that checkpoint's `next-question/DECISION.md` and `next-question/CHALLENGE.md`. They select the new three-arm/two-origin prospective diagnostic, not another execution of an old budget.

`prepare-source.py` reads the baseline by an explicit argument, verifies its hash and applies checked text replacements. It was executed only as source editing: it never imports a scientific module, parses/compiles WGSL, generates a seed/state/axis/offset, or evaluates model arithmetic. Generated `coordinate.wgsl` retains the original independent-I policy, dot expression, factored fade, profile expression, scalar controls and serial addition semantics. Added vector diagnostics use raw u32 members and explicit reached masks. Node loading, residual validation, per-arm entrypoints, the local-first expressions and the new reducer masks are the prospective changes.

`materialize-controls.py` reads the old literal JSON with SHA-256`55035545e61ca16d0c112b45e278ae94e4cb31fb7940bc8dd567cd9f95796219`. It copies the first16×32u32words, appends literal zeros and four explicitly specified u32control records, then uses `struct.pack('<40I',...)` for little-endian integer encoding. It contains no f32 conversion, geometry/profile/root calculation or expected-output model invocation. New expected masks and direct nonzero dyadic vectorword literals are fixed source assertions, not measurements. This static literal encoding is disclosed separately from all future scientific work.

The added residual bound2^-17 is conservative for admitted absolute high coordinates≤128 under round-to-nearest f32 splitting; the host's chosen construction has stricter bounds and separately verifies exact semantic reconstruction. The shader does not assert high/low nonoverlap or reconstruct absolute f32 positions. Difference component guards257and258 cover the admitted high/low/offset magnitudes with slack and precede norm/dot use. They are arithmetic admission guards, not empirical ranges or changed finite-support policies. All former scalar bounds remain.

WGSL source parentheses and intermediate names do not fix backend fusion/reassociation. Returning the actual vectors makes a relevant result observable, with the limitation stated in the contract. No extra pass forces a boundary. Actual compilation, layout validation, device behavior, performance and scientific accuracy are unknown until the independently reviewed, frozen and published future invocation.

Static checks may inspect text/member counts, integer controls, byte lengths, expected masks and hashes. They are not shader type checking, compilation, numerical evaluation, or a prediction that every gate will pass. No new GPU/browser execution, model import, float-control encoding, binary scientific-state decoding or benchmark occurred in this preparation. All former budgets remain closed.
