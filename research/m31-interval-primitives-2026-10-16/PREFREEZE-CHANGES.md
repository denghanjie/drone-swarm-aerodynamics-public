# Prefreeze source review changes

No scientific code was imported or evaluated to make these changes. Initial case-generator/runner/contract files remain in prefreeze/initial-source, and PROTOCOL-DRAFT remains unchanged.

The independent protocol reviewer showed algebraically that the first pair-selection rule forced left-even/right-odd indexes: an odd-multiplier, odd-increment LCG alternates parity, and the interval count is even. That rule omitted every self-pair and important explicit operand combinations. The current specification keeps 256 pairs but makes the first 48 explicit (24 self-pairs and 24 directed boundaries), followed by 208 high32-bit-derived index pairs. The supplement is deterministic and is not claimed independent or representative of all intervals.

The same reviewer noted that writing only the final result could lose completed evidence after a failure. The runner now opens an exclusive journal before generation, writes each completed case and periodically fsyncs, then writes a completion marker before the final document. The checker must establish complete journal/final-record equality and preserve failed partial attempts. Numerical fault controls call the same core validator on altered result documents, so a journal mismatch alone cannot masquerade as a numerical error-detection test.

The count remains 1,488 primitive records. Fault controls have five categories, with duplicate and reordered records tested separately (six mutations). A wrong endpoint must exclude a known exact value or violate the explicitly required canonical lattice endpoint; widened-but-enclosing output alone must not be called an inclusion failure.

The first supervisor also needed revision. Its original source is retained in prefreeze/supervisor-v1. The revised version retains a live group guardian while the scientific child runs and releases it only after child exit; it does not signal an exited leader ID. It pins executable bytes, records command templates, rechecks source/runtime after the child, verifies prior-stage source/output/journal identities, accounts for public-log copies in final size, and checks supervised time through postrun identity verification. The protocol now reports actual sample gaps rather than promising a sub-0.1-second interval. Sampling and reviewed no-subprocess child code are explicitly distinguished from arbitrary hostile-code containment. Missing final reports are unqualified, not success.

A second supervision review identified two further source-chain/cleanup gaps before execution. Guardian cleanup now runs in finally independently of lifecycle-journal writes, with best-effort error logging and a SIGTERM handler that permits reaping. Postrun identity checks now compare the source manifest and publication receipt bytes themselves, require all scientific/protocol/runtime sources in the manifest, and retain/recheck the prior kernel supervision/output/journal pins after the checker. The revised sources are reviewed again before freezing; no result-bearing retry is involved.
