# Source-only host API

All exports are inert on import. Only syntax checking has been performed. `independent-frozen.source.txt` is a provenance copy, never imported. Parent driver owns persistence, timers, one-attempt lifecycle, byte/RSS caps, browser and saved-review launch. All scientific functions accept `{guard,charge}`; both callbacks are synchronous and exceptions terminate. Pass them to construction, reference, handoff, host controls and assessments.

1. `createConfig()` returns `original`, `decoded`, `packedConstants:u32[32]`, `gates`, `names`, version. This explicit call computes constants once inside science. `constantsFor(C,N)` clones32 words and patches onlyword20; save actual dispatch bytes.
2. `prepare(states,C,options)` takes original17-component state rows and returns `N, originalStates:f64[17N], candidatePrepared:f64[28N], referencePrepared:f64[28N], decodedPrepared:f64[28N], packed:{nodes:u32[8N],offsets:u32[16N],motors:u32[4N]}, admission,completed,status`. Every28-f64 prepared row is node8 + offsets16 + motors4. R matrix rotation and production double-cross rotation are separate. Errors carry no-copy `{kind:'preparation',buffers,metadata}` partials.
3. `runReference(p,'R'|'Q',C,options)` returns `{path,N,policy:u16[N*N],output:ArrayBuffer(480N),counters,completed,status,failure}`. Explicit numerical/domain failures return `completed:false` and actual prefix; guard errors attach this same object as `error.partial`. Persist before testing completion.
4. `assessStimulus({generated,prepared,R,Q},C,options)` checks already completed reference paths, generated input metadata and designated R sums>=.25. No geometry/profile/root solve. Save and require pass before GPU.
5. `runHandoff(GPU.output,p,C,options)` returns `{N,output:ArrayBuffer(288N),counters,completed,status,failure}`. It solves only at raw actual GPU nominal/inflow; one scalar attempt per reached rotor. Persist before testing completion.
6. `assess({prepared,R,Q,GPU:{output,policy},H,designatedReceiverIds},C,options)` returns bounded metrics, up to64 failure samples, pass, integrityPass, counters, completed. All required records/policies checked. `integrityPass` fails incomplete/invalid/inconsistent records or candidate reference-quality premises. Valid direct R/H output or policy-class differences make `pass:false` while retaining integrity. Every array is consumed as saved data; no field, bisection or Newton evaluation. Scalar coefficient, polynomial and body recompositions are explicit saved-arithmetic checks. Inward final comparisons use exact dyadic BigInt differences/margins against stored binary64 thresholds.
7. `buildControls(C,options)` returns `{pairs:{count:15,input:u32[960],original:f64[240],expected:Array15,outputsBytes:3840},roots:{count:146,input:u32[9344],original:f64[292],definitions:Array146,outputsBytes:37376},hostOnly,completed,status}`. Save both raw packet arrays and original operands; use literal CONTROL-MATRIX.md plus returned definitions/expected as metadata. It computes only fixture construction, including explicitly counted vstar sqrt definitions; no receiver solve.
8. `runHostOnlyControls(controls,C,options)` returns bounded actual expected/observed records for P15 plusA00..11 and16 decoder cases; save and require completed&&pass. Only designated BodyContractError messages count as expected rejection.
9. `runControlsReference(controls,C,options)` returns `{pairs:{R:Array15,Q:Array15},roots:{R:ArrayBuffer(146*96),Q:ArrayBuffer(146*96)},counters,completed,status,pass,failure}`. Save nested root buffers as binary, pair records as bounded JSON, and status/counters separately. Require completed&&pass before GPU controls. Do not JSON-serialize ArrayBuffers (would lose their contents).
10. Dispatch `controlPairs` and `controlRoots` once each with constants0,input6,output7. Then `runControlHandoff(GPU.roots,controls,C,options)` (singular) returns `{output:ArrayBuffer(146*64),counters,completed,status,pass,failure}`; save before requiring pass. GPU.roots here is raw output, not `{output:...}` batch wrapper.
11. `assessControls({controls,references,GPU:{pairs:rawPairs,roots:rawRoots},H,hostOnly},C,options)` consumes those saved outputs and returns bounded metrics/pass. No scalar solves.

Control-construction/reference/handoff and assessment guard errors use a common no-copy `error.partial={kind,buffers:{...},metadata:{...}}`; metadata includes bounded completed records/counters. Main references/H retain their conventional output/policy partial shape. Driver must wrap each explicit call and persist partials before propagating failure.

`WORK-LEDGER.json` enumerates every emitted charge name and conservative prospective maximum. Root attempts include identities, but identities have no bisection solve/update. R/Q field counters are delivered once per receiver or explicit failure return; raw counters preserve actual work on interruption. Pre-GPU and post-GPU designated exposure scans are separately named/counted. Candidate field terms are never retained/replayed. Save exact typed views respecting byteOffset/byteLength.

This module does not implement the independently bounded saved-review launcher. The frozen saved-only reviewer must not call any scientific construction/reference/handoff exports.
