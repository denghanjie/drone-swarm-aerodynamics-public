# Reproduction and dependencies

Requires Node 24.19.0, nonoptimized Python 3 with NumPy, Git and the existing repository dependencies. No installation is allocated. Candidate is serial CPU numerical code; Three.js later replays saved data in a browser. Source-manifest.json pins every inherited scientific module and reference record; retain its paths from repository root. Do not run scripts in historical closed result directories.

Source publication and exact remote manifest retrieval/local-and-committed pin verification precede execution. With HEAD fixed to the verified source commit, exactly once each:

```
python3 research/m31-ratio-reuse-2026-10-16/source/run.py candidate NODE_EXECUTABLE VERIFIED_SOURCE_MANIFEST_SHA PUBLISHED_SOURCE_COMMIT
python3 research/m31-ratio-reuse-2026-10-16/source/run.py review PYTHON_EXECUTABLE VERIFIED_SOURCE_MANIFEST_SHA PUBLISHED_SOURCE_COMMIT
```

Use approved host supervision capable of querying process RSS. Candidate and reviewer have exclusive locks and fixed budgets; an error consumes the allocation. Preserve unsuccessful runs. No concurrent heavy benchmark. Parsing with `node --check`/Python ast.parse is allowed pre-freeze; importing model modules is not.

An external independent reproducer must use a separate checkout/output package and preregister that reproduction; never remove these invocation locks or overwrite published results. Runtime/environment differences must be disclosed. CPU timing of this single instrumented evidence run is not a performance benchmark.
