# Prospective independent checker implementation

The checker was authored without reading the new binary64 arithmetic, zero filter or runner source. The exact runner interface was supplied by the parent. The retained source inventory identifies six inherited files read under the cap of twelve. No numerical imports, candidate calls, old-suite calls or checker execution occurred while authoring. AST parsing, JSON syntax/allocation inspection, hashing and the separately authorized literal serialization were the only checks executed.

`source/check.py` has no candidate imports and spawns no subprocesses. After source closure and buffer pin checks, its sole dynamic module is the unchanged local `source/semantic-reference.py`, pinned to SHA256 `845f52cf350a09d2043934dff3e797a7b7416f4ef5c64beb716104bcd74f38f0`. Only its preparation/constants/oracle and exact-rational utilities are used. Its old validation main, case regeneration and controls are not called. The helper is an inherited trust boundary, not a freshly independent proof of the whole physical law.

The checker requires eleven local source/protocol/runtime files plus the five inherited baseline dependencies in the source manifest. It validates raw bytes before compiling the helper, checks the running Python binary pin, and rechecks source, manifest, result, journal and Python binary after mathematical validation and before writing evidence. The supervisor provides the external public-source gate, Node runtime identity, exclusive allocation and post-exit artifact checks. Compact JSON retains runner insertion order rather than sorting keys. Ordered journal comparison is structural after exact compact-line byte validation. The journal is provenance, not proof of actual computation.

Primitive references use exact rational endpoint arithmetic and integer IEEE word adjacency. Nonfinite inputs, reversed intervals and zero-enclosing divisors must refuse. An arithmetic fallback is allowed on otherwise valid inputs, but each arithmetic operation must produce at least one enclosing finite interval and all fixed corruption witnesses must exist. Finite maximum stepping may produce an infinity word sentinel; a returned arithmetic interval may not contain any nonfinite endpoint. Squaring a zero-crossing interval uses an exact zero lower bound.

The full raw states independently regenerate preparation, including its rejection precedence and retained prepared object. Both baseline and candidate scalar outputs are independently checked against the fixed192 oracle before their full structural equality is checked. Every positive interval K, scaledK, beta, nu and coefficient must enclose its independent reference; positivity and cap certification are checked. Candidate fast zero must match the original exact branch; preparation rejection cannot enter the filter. Exact fallback identity includes every interval and branch.

All fixed96 unresolved statuses fail qualification, including range, cap and normalizer refusals. They cannot be accepted by replacing their status with a more decisive fixed192 status. Every fixed192 reference-undecidable status likewise fails. There are no inherited stress exceptions in this cycle. An unresolved case may be retained as a failed result, but is not a required success witness.

Sixteen new controls run against a single precomputed independent reference set, one copied document at a time, without replaying the candidate. Each fixed recipe requires its independent mathematical or coverage/provenance witness and the intended failure code. Semantic status, branch and enclosure checks precede baseline equality. The journal control mutates only a journal row. Missing witnesses or a passing mutation fail qualification. Useful fast-zero and positive-fallback witnesses are mandatory; all six zero branches need not be hit.

The output is a bounded reference artifact and validation/control report. This is finite scalar verification only: no full load solve, complete-group cost estimate, moving dynamics, browser scaling, physical validation or novelty claim follows.
