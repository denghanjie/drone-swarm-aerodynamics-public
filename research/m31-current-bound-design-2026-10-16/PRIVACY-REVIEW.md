# Public-artifact review

This package contains authored research notes, exact preserved reviewer reports, bibliographic/access metadata, source hashes, a static explanation wrapper, its UI runner, screenshots of that local research page and a display QA report. No user attachment, private chat record, original paper asset, credential or personal contact information is included. Runtime executable paths are environment variables in the public runner. Reviewers wrote public-safe relative paths; no content redaction was required when copying their reports. The report import hashes identify byte-preserved originals and public copies.

Metadata checks scan authored text for private local paths and credential-like patterns before publication. Every JSON record is parsed, every new public file is pinned, all referenced source pins are compared to their bytes, and historical viewer asset pins are checked against the published result manifest. Hashing historical assets does not reanalyse their scientific arrays. The old full manifest is retained as a reference rather than republishing its results under a new claim.

These checks support publishing this checkpoint. They do not establish mathematical correctness, measured speed or aerodynamic validity. UI screenshots contain only this research page and its synthetic recorded swarm.
