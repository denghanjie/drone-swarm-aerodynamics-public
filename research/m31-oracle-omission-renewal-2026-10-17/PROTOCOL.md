For each row, retain all reference-positive terms, including any whose lower endpoint is zero. Validate all reference statuses, indices, intervals and complete pair coverage; zeros must be explicit and carry no coefficient. Refused/unresolved/missing/invalid evidence stops interpretation. Negative lower endpoints are rejected as outside this saved-reference contract, never silently dropped. A zero-positive state is retained with undefined percentage and no opportunity pass.

1. **Optimistic singleton ceiling:** sort positive lower endpoints by value then stable source ID; take maximal prefix whose sum <=b. Exact rational sums. Every feasible omitted set of k terms must have lower mass at least the k smallest lower endpoints. This prefix count therefore upper-bounds possible omitted-positive count under this proxy. It need not be attainable.
2. **Feasible oracle singleton control:** sort positive upper endpoints by value then ID; take maximal prefix with sum <=b. This lower construction separates interval uncertainty from the additional tree-policy restrictions. It is not a runnable approximation.

T8 stops at8; T2 uses the same rule at2 and must retain every T8 member set. Verify T8 structure/permutation against saved baseline. Visit root, then left before right. A self-free whole node with at least two reference-positive members can be selected if the sum of ALL member coefficient upper endpoints fits the remaining cumulative row budget. Include explicit zeros. Stop descending accepted nodes. Otherwise descend; unselected leaves retain all their nonself members. No invented subleaf, reference-driven tree geometry, overlapping nodes, or one-positive budget spending. T2 is a prospective diagnostic refinement, not a qualified model implementation.

Greedy T8/T2 counts are feasible oracle examples, not optimal grouped ceilings. Refinement or a larger budget can decrease a greedy count; preserve it.
