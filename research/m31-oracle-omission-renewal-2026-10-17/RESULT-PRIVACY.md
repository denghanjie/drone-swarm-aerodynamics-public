# Result publication review

Results contain synthetic drone identities, exact rational coefficient-mass bookkeeping, selected/retained memberships, diagnostic counts, fixed fixture/corruption outcomes and bounded execution metadata. They introduce no physical dataset, personal record, credential, hostname, hardware serial or user attachment. Source identity uses public commit/hash values. Numerical values are unmodified.

The parent scans new text for personal installation/temp paths, credential-like patterns and private-key headers. Viewer screenshots are inspected for research UI only. Display adapters copy saved numerical values without generating poses; derived rounding is presentation-only and source counts remain exact. Existing Three.js notices are retained. This bounded privacy review is not a guarantee of recognizing every secret format.

The earlier failed allocation, all frozen input/source pins and scientific output bytes are preserved. Viewer QA and independent postrun checks document those comparisons. Exact result-manifest pins cover the actual published bytes; mutable root navigation is excluded. No paid service, author contact, paper submission or new data-sharing license is involved.
