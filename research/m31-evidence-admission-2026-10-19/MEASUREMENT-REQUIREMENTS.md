# The next useful evidence, in plain terms

We need a trustworthy ruler before deciding how to change the model. The immediate research destination is an experiment specification; this file is a requirements draft, not a launch protocol or a promise that an experiment is available.

1. **Measure the air moving down and sideways.** Supply signed Cartesian components, not just speed. More than one vertical plane or a volume is needed to distinguish swirl/nonaxisymmetry from a faulty radial prediction. A single plane supports only a conditional plane test.
2. **Know where the readings were taken.** Record exact rotor centers, radius, cant, heights, body layout, sheet positions, coordinate transforms and distances from walls. Retain the model's current far-downstream domain; derive the physical coordinate mapping before any target score. A different aircraft may require a new model question, not a silent geometry substitution.
3. **Keep the conversion trail.** Preserve acquisition timing, spatial calibration, signed components in m/s, operating point, thrust and density if a normalizer is used, averaging, masks, stitching and uncertainty. Export raw/processed files with version, license and processing code. Report spatially correlated errors and run-to-run variation where available.
4. **Decide the test before seeing its answer.** Freeze model constants and any physically justified scale, domain, masking, primary component errors, exclusions and uncertainty method. The old fitted gain is not a universal unit conversion. Choose repetitions/sample size from measurement precision or separate pilot information, not invented counts. Preserve failures and null outcomes.
5. **Compare explanations using distinguishable measurements.** Repeated calibration checks can address scale errors; multiple planes/components address symmetry and swirl; several downstream sections address axial evolution. These are proposed discriminating observations, not evidence that any explanation is true.

Within current permissions we can turn this into a documented acquisition/analysis design. We cannot manufacture experimental evidence through animation or simulations. No hardware purchase, author contact, physical flight, new data download, experiment or numerical test is launched by this document. Reopen admission only for genuinely new accessible provenance or a new compatible release; maintain existing exclusions.
