# Minimal candidate for independent source review

Status: draft only; no import, target evaluation, control evaluation, profiling or timing. The adjacent patch is the complete proposed computational change relative to the moving-admission pair-prepared.cjs and methods.cjs. All other dependencies would be copied unchanged into a later frozen experiment.

The method creates a fresh query closure after spatial preparation and before its scan. It owns two WeakMaps and exposes only the query function. Source-object identity keys beta; receiver-object identity plus integer rotor index keys nu. The exact prepared objects are freshly constructed inside this method invocation and are not exposed until method return. No cache is stored at module scope or returned in the method record. A subsequent method call constructs a new closure and new exact objects even if stable drone IDs repeat.

At the original beta/nu expression sites, compute the exact same rational operands and directed square roots in the same beta-then-nu order. A hit substitutes the already-computed frozen interval. A miss stores only after successful computation. No value is precomputed for a zero or refused geometry path; no exception is cached. An interval may be retained even if the later cap/normalizer check refuses this particular pair, since the original computation succeeded and its dependencies did not change. No cap, branch, coefficient, load, solver or certificate is cached.

The original uncached query remains available under the same three-argument interface. Draft methods.cjs calls the fresh closure for every exact fallback; method name and output schema remain filtered. Scientific work counters still describe the same pair/filter work and should be byte-for-byte identical. Additional instrumentation must remain out of these drafts until separately specified; counter decreases are not the cost outcome.

Proof obligations: all exact source forces and constants remain unchanged throughout an invocation; arithmetic functions read operands without mutation; successful interval objects are frozen; synchronous execution has no state-mutating reentrant callback during assembly; pair traversal and exception priority are unchanged. This proof concerns the closed admitted method path, not arbitrary users mutating objects passed to exported createQuery. A later API must not advertise safe reuse across state mutation.

The cached computations are beta=sqrt(sum(source forces)/mg) and nu=sqrt(receiver rotor force/(2*rho*A)). For Q queries that reach these expressions with successful calculations, the uncached path performs up to Q evaluations of each, while the candidate needs at most N source-beta values and 4N receiver-rotor-nu values per method call. Failures are recomputed and do not share that successful-work bound. This is an operation-count bound, not an empirical bottleneck or speedup.

Timing must include factory creation, cache lookup, successful misses, method-local memory, unchanged admission/geometry/assembly/solve/certification and method return. Allocation and later garbage-collection effects must be addressed explicitly. Changing just these computations limits attribution; other repeated geometry remains untouched. A fresh paired experiment must check entire records exactly and independently validate all scheduled states, including refusals.
