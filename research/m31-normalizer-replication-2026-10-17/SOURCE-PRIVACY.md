# Prospective source privacy review

Publication contains project source, fixed synthetic controls, source-derived flight settings and seeds, exact runtime hashes, relative file identities, prior public literature/evidence references, bounded source reviews and the protocol. No user attachments or private chat records are copied. The seed inventory contains only repository-relative inspected paths, sizes and hashes. The protocol records standing authorization without reproducing the user's private brief.

Runtime installation paths and raw-log directory locations remain caller environment configuration. The supervisor replaces machine/home/runtime prefixes in public error logs, retains only owned-process lifecycle observations, and leaves raw stdout/stderr outside the repository. Its source contains a literal private-temporary-prefix redaction pattern; that is sanitization code, not an actual machine path. Public runtime hashes identify the exact executables but not their local installation locations.

The parent scans new textual artifacts for home paths, concrete private temporary paths, private-key headers and common token patterns before staging. Source reviews include historical exposed evidence clearly marked as inherited; no new target trajectory or numeric candidate evaluation has occurred during source preparation. This finite scan does not prove universal secret detection.

The public source checkpoint is authorized by the standing research request. No external contact, paid service, raw physical dataset redistribution or paper submission is performed.
