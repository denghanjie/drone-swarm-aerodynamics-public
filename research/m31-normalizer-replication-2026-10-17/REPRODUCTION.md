# Replication allocation

Execution is one-shot and requires this package's published source commit at HEAD, exact HTTPS source-manifest verification, and source/runtime pins. Do not execute in a completed evidence checkout or remove attempt markers. A later reproduction needs its own prospective allocation; published result bytes remain immutable.

Use the pinned Python binary with -I -B and pinned Node binary. RESEARCH_NODE points to Node; RESEARCH_PRIVATE_RUN_DIR is a new empty directory outside the repository. RESEARCH_EXECUTION_CONTEXT=tool-require-escalated records the caller attestation. Invoke source/supervise.py kernel with explicit require_escalated tool permission, await complete closure, then source/supervise.py checker under the same dispatch. No NODE_PATH/NODE_OPTIONS or loader injection. The supervisor verifies committed source, runtime and publication identities before consuming the sole attempt.

Runtime paths and private raw log locations remain local configuration rather than public machine metadata. Scientific source/config pins identify exact methods and seeds. The inherited baseline and two candidate modules are unchanged from the failed experiment; only allocation and reviewed lifecycle integration are new.
