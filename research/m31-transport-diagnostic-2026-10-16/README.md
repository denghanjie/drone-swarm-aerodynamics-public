# Milestone 31: tracing one evidence transfer

The previous experiment failed while saving its first GPU output, before any main drone case ran. We are preparing one small test using known bytes to observe the transfer itself.

This is a transport diagnostic. It contains no drone or aerodynamic calculation. Even a pass would not explain the previous failure, because ordinary memory differs from the GPU-mapped memory used there.

Read [the prospective protocol](PROTOCOL.md) and [the independent scope challenge](design/INDEPENDENT-SCOPE-CHALLENGE.md). No transfer has yet been launched. Source review, freeze, publication and independent verification must come first. All earlier attempts stay closed. No follow-on scientific run is automatically authorized.
