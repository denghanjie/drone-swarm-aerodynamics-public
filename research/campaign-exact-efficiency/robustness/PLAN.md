6. Measure costs only under an explicit exclusive serial measurement window, with one heavy process active. Separate field-only, field plus receiver-load, and actual full pipeline scopes. Full-pipeline results must include the unchanged Boids/controller/physics/safety schedules; a field-only gain is not a whole-flight gain. Use warmup, seeded randomized/alternating method order, repeated paired measurements, checksums, raw per-repeat times and process-memory snapshots. Report measurement scope and sampling/serialization exclusions precisely.
7. Initial sizes are at most 200. Scaling above 200 through 500 needs an additional frozen decision and a exclusive serial measurement window; no automatic extension. Retain zero/isolated, sparse and dense negative controls. Report small-N regressions, density effects and workload-specific outcomes.
8. Report exact-equivalence and timing outcomes separately, failures, reproducibility, source changes, and limitations. Check final Three.js replay data identity and browser behavior if a supported browser is available. Do not repeat or work around the previously denied Chromium socket launch.

## Frozen correctness gate

For model-domain-valid finite 17-entry states with unit quaternions and nonnegative nominal thrusts: maximum rotor inflow discrepancy <= 1e-12 m/s, maximum force-vector discrepancy <= 1e-12 N, maximum roll/pitch moment-vector discrepancy <= 1e-13 N m. Compare finite shape, four-rotor retention, positive interaction preservation, source/input mutation and model-domain outcomes. Run identical receiver law for field comparisons, and compare exported new loads separately. Record bitwise differences without requiring bitwise equality when arithmetic order changes. A discrepancy stops promotion until diagnosed; no threshold relaxation after results.

Malformed API inputs (NaN, infinity, nonunit/zero quaternions, wrong shape, invalid options) are isolated, bounded tests because the legacy grid can hang. Empty-array behavior and stronger validation are API compatibility questions, not physical model changes. Record legacy versus previous versus new behavior without requiring preservation of unsafe behavior. Negative thrust is a receiver-input domain issue even if fields do not consume it. Explicitly document any adopted contract.

## Frozen performance gate and controls

Primary claim of a useful field-speed improvement requires >= 10% median saving versus legacy, paired 95% bootstrap ratio interval entirely below 1.0, and correctness pass on at least two held-out N >= 100 scenario families. Also report the same comparison against the previous zero-budget implementation; do not conflate removal of its bound computation with new physical pruning. A whole-pipeline claim must independently pass the same criterion on its own measured scope; otherwise report observed numbers without a win claim. This is a provisional same-host numerical benchmark, not hardware-generalized performance or a flight-feasibility result.

Use development seeds 628731 and 628732 only for debugging; held-out seeds 628791 and 628792 for frozen measurements. Timing order seed 7735201. At least 9 paired repeats, 5 untimed warmup evaluations per method, and enough bounded batch evaluations to make sub-millisecond timer noise visible rather than decisive. Record Node/platform/CPU, source hashes before/after, load averages, wall/process usage, timestamps, checksums and process RSS/heap/external bytes. Memory deltas are noisy process observations, not allocation-rate or peak-memory claims. Never run correctness sweeps or other heavy work alongside timings. Complete each bounded job within its approved serial measurement window and write partial rows incrementally on failures.

## Artifacts and stop conditions

All independent files live in this robustness directory. Portable scripts resolve an explicitly supplied repo root or their documented published placement, not a private machine path. Raw fixtures, outcomes, config, manifest, incremental timing rows, failures and a concise report are retained. Reviewed publication is managed separately. Stop promotion on nonfinite values, hidden model-domain failures, source mutation during measurement or unmet exactness thresholds. No paid compute, no evidence-bundle download, no silent source changes and no destructive actions.
