# Source privacy scope

Public source contains original simulation code, fixed synthetic scenarios, public source/reference hashes, literature citations and a numerical experiment protocol. Referenced previous records contain synthetic drone states only. No user attachments, local absolute paths, credentials, private correspondence or third-party report payloads are intended for publication. A narrow source scan and pin verification precede commit. New scientific output remains separate until result review. This is not an exhaustive audit of historical repository content.
