# Frozen output / audit contract

All paths below are relative to this new checkpoint unless explicitly repository-relative. JSON uses sorted keys, compact separators, ASCII escaping and a trailing newline. stages.jsonl is one such object per line. Ratios remain exact count pairs until display formatting.

source-manifest.json: {schema, files:[{path,bytes,sha256,kind,originCommit?}]}. path is repository-relative. kind is source or input. source pins freeze new scripts/docs/viewer/runtime/config and all three local Three.js vendor modules. Input pins carry an immutable originCommit (previous result 0461153... or final receipt d948a58...). The manifest itself is committed and its exact hash/bytes/commit appear in source-publication.json with remoteBytesEqualLocal,committedBytesEqualLocal,independentReviewPassed=true and verifiedFilePins. No manifest self pin. source-publication is created only after independently checked public source. Every source pin is checked before each allocation. Inputs are read from their pinned committed blobs, never model code imported.

results/stages.jsonl: 1920 objects in window/index order, each:
- window,index,caseId,globalOrdinal,sourceLineSha256,selectedRecordSha256 (hash of complete decompressed selected line including newline),timeWord,time,status,reason,nativeStage (null for success),admissionReasons (saved list);
- ids: 64 original canonical integer IDs; positions: decoded nativeInput state[0:3], exact binary64 round trip;
- counts: logicalPairs, componentSurvivors, componentRejected, guardRejected, radialRejected, centerEligible, rotorCalls, positiveRotorTerms, positiveVehicleEdges, supportedZeroRotorTerms, unsupportedNearFieldRotorTerms, invalidRotorTerms;
- symbols: 12 saved integer symbol counts.

No original native/coefficient/state record is regenerated; six old exact published parts remain the full source evidence. NativeInput words and prepared centers must agree, positions/time/status must agree bitwise with previous audited viewer. Counts are saved builder integers plus the fixed integer differences/sums in the protocol. U=graph.uniqueVehicleEdges is positiveVehicleEdges; require 0<=U<=E and U<=T<=4U (or both zero). Reconcile U from the union of saved CSR sourceIndices over each receiver’s four rotor rows, sum across receivers. Require offsets length 4n+1, monotonic integer offsets from 0 to T; each rotor row sourceIndices strictly increasing, in [0,n), no self index, and each K word finite and positive. This is a saved positive-coupling count, not a count of all status-relevant pairs.

results/summary.json: {schema:'m31-neighbor-density-summary-v1',stages:1920,nativeCalls:0,countsKeys:[the12keys above],overall,windows:[12groups],byStatus:{'native-success':group,'domain-refused':group},refusals:[{window,index,caseId,globalOrdinal,timeWord,status,reason,nativeStage,admissionReasons}],decision:{componentOpportunityExists:bool,radialOpportunityExists:bool,bufferWidthTuningForTheseClips:'retire'|'unresolved',radialFollowup:'consider-separate-proof'|'no-distance-headroom-observed'},scope:'saved exposed N64 builder counts; no timing or physical inference'}.

Each group is {stages,totals:{key:sum},min:{key:min},max:{key:max},componentNonzeroStages,radialNonzeroStages}. Each windows entry adds window,caseId,start. Status groups are required nonempty for this known exposed archive; mismatched input identity/status census fails rather than being hidden.

results/input-binding.json: sourceCommit, sourceManifestSha256, original selected archive descriptor and exact prior input pins consumed; readEvents. results/exit.json: closed,exitCode,wallSeconds,readEvents; on failure preserve results/failure.json. Producer supervisor is separately recorded. No timings from this diagnostic can be presented as benchmark performance.

audit/audit.json must include passed=true only after every input identity, closed successful producer supervisor/exit, every row, totals/min/max/status/decision and exact data/summary serialization agree. Include independently computed summary, stages=1920,nativeCalls=0, sourceManifestSha256, filePins for results/stages.jsonl,summary.json,input-binding.json,exit.json, selected archive identity and readEvents. Independent implementation must not import producer/common helpers. audit/exit.json and failure.json preserve closure/failures. Every runtime failure leaves closed allocation and requires distinct protocol, never edits/retries of the same run.

finalizer writes viewer/pins.json for data(results/stages.jsonl),summary(results/summary.json),audit(audit/audit.json),producer(producer-supervisor.json),auditor(audit-supervisor.json); each descriptor uses file,bytes,sha256 relative to new checkpoint. UI only consumes these bound artifacts. It does not calculate memberships, forces or flight paths.
