## Root-defect argument and candidate implementation

The adopted arbitrary-root corollary follows from the inherited log-space source contraction of at most one half and log-root sensitivity of at most one. For `P(x)=x^3+alpha*x`, `alpha>=0`, the logarithmic derivative on `x>0` is

`d log P / d log x = (3*x^3+alpha*x)/(x^3+alpha*x) in [1,3]`.

At a recorded `0<xhat<=1`, build the exact candidate-derived source `yhat=sqrt(sum w*xhat)`. Let `p_ir=P_ir(xhat_ir)`, `k_ir=max(p_ir,1/p_ir)`, and `K=max k_ir`. The polynomial derivative bounds the local log-root defect by `log k_ir`. The source consistency defect is at most `log K/2`; contraction bounds source error by `log K`. The log-root sensitivity then gives

`xhat_ir/(k_ir*K) <= xstar_ir <= min(1,xhat_ir*k_ir*K)`.

Zero rows cause no singularity. Both the local and global factors are necessary for an arbitrary candidate. This is the inherited conditional corollary, not a new contraction claim.

The candidate's forty-eight synchronous iterations, native nominal weights, midpoint coefficients, and fifty-four-step cubic bisections are an untrusted proposal. Each iteration constructs all source amplitudes from the prior rotor array before replacing that array, so the implementation is synchronous. The emitted binary64 candidate bits are checked for finite `0<xhat<=1`. Native candidate computation is not a mathematical accuracy premise, and the checker deliberately does not replay those native iterations bit for bit.

The certificate reconstructs exact rational weights and exact rational weighted candidate sums from the emitted bits, then outward-encloses their square roots. Each complete row contraction is an interval sum of the admitted coefficient intervals times those source intervals. The polynomial enclosure includes the recorded candidate, its cube, and the complete returned row sum.

For a defect enclosure `[L,U]` with `L>0`, the implementation takes the outward upper reciprocal of the **lower** endpoint and forms `kbar=max(1,U,1/L)`, then the maximum `Kbar`. Both factors are explicit lattice values. Their product is outward-enclosed. Lower root division and upper root multiplication consequently enclose the exact corollary endpoints; intersection of the upper endpoint with one uses a proved model bound. This is not clipping an invalid candidate. A range failure or nonpositive defect lower endpoint produces a named unresolved outcome.

The checker independently requires each row sum to include the full returned positive coefficient boxes times a source enclosure of the exact candidate-derived weighted square root. It requires the saved defect to contain the exact candidate polynomial evaluated over that returned row sum, then checks the factor inequalities and exact rational corollary endpoints. These checks prevent a narrow certificate for a different candidate, stale row, or incomplete coefficient set from being accepted merely because it happens to contain a reference solution.

## Explicit extension from body roll/pitch to world moment

The older body-load corollary writes roll as `sum y_r*D_r` and pitch as `-sum x_r*D_r`. Those formulas describe the body-frame special case with lever `(x_r,y_r,0)` and force direction `(0,0,1)`. They do **not** establish a zero world-z moment or permit treating a near-unit prepared axis as exactly unit.

For this package, let `o_ir` be the separately prepared lever arm, `a_i` the actual prepared axis, and

`v_ir=o_ir × a_i`.

The exact supplied-geometry map is

`t_ir=f_ir*x_ir`, `T_i=sum_r t_ir`, `F_i=a_i*T_i`,

`M_i=sum_r v_ir*t_ir`.

For a root interval `[l_ir,u_ir]`, candidate-minus-solution rotor error is enclosed by

`D_ir=f_ir*[xhat_ir-u_ir, xhat_ir-l_ir]`.

Signed interval multiplication and summation give `Delta M_ik in sum_r v_irk*D_ir`. If the resulting coordinate interval is `[L_ik,U_ik]`, define `b_ik=max(abs(L_ik),abs(U_ik))`; then `sqrt(sum_k b_ik^2)` is a conservative world-moment norm bound. Coordinate dependence may loosen this box bound but cannot invalidate it.

The proof uses the exact signed linear map of the actual supplied axis and offsets. It needs neither an exactly unit axis nor exact offset/axis orthogonality. Each cross product is perpendicular to the supplied axis in exact arithmetic, but its world-z component need not vanish. This is not a physical yaw statement. Offsets remain separate prepared operands; subtracting the center from a rounded rotor point could change them and is not used.

The inspected candidate and checker both implement `offset × axis` in the correct order and retain all three world coordinates. The candidate computes exact rational rotor, collective, force, and moment values from the recorded candidate. It encloses the signed map of the returned root boxes using directed fixed96 arithmetic; the checker requires those returned load boxes to contain both the exact signed propagation of the entire returned root box and the independent model-load reference.

For collective error, the signed rotor differences add. For world force, the actual axis multiplies the collective interval. The implementation encloses all three force components and evaluates their error norm; it never substitutes a unit-axis norm. For absolute values and Euclidean norms, using box-minus-candidate rather than candidate-minus-box changes signs only and yields the same required maximum magnitudes.

## Full-box errors and exact tolerance
