# Publication review

This package contains original public CC BY4.0 laboratory PIV arrays, public attribution, source, review notes and derived analysis. MAT headers were inspected: format/platform/creation dates only. No private flight paths, addresses, credentials, original user screenshots, chat exports or personal messages are included. Source/text scan found no private absolute paths or credential patterns; the CSS @media rule is harmless. Reviewer acquisition paths were replaced with PRIVATE_ACQUISITION/ while retaining source hashes. Source review identities and reproducibility details are intentionally public. Future result publication will additionally inspect generated command logs for local-path leakage and disclose any public sanitization without changing scientific evidence.
