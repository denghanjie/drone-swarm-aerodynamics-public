The implementation imports only Python standard-library modules. File/JSON/identity helpers are reused as source text from the prior independent auditor, with this reuse disclosed. No prior audit, producer, candidate or scientific module is imported. The rational rounder, certificate checker, cache lifecycle and per-pair accounting are independently authored.

Round-to-nearest/ties-to-even is reconstructed using integer quotient/remainder, a floor-log2 exponent, an explicit subnormal branch and carry handling at a significand boundary. No floating multiplication or square root participates in this certificate oracle.

This declared basic-operation assumption is narrower than an independent intrinsic oracle and is reported explicitly. Finite binary64 comparisons implement inclusive containment. The audit uses no Python `hypot`, norm or square-root replacement.
