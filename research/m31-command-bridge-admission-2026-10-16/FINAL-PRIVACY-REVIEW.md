# Publication review

The package contains our methods notes, verified citations, exact independent review and sanitized access receipts. No source PDF, figure, complete data table or target value is redistributed. The review hash matches the recorded handoff. Public text was checked for private filesystem paths, secret patterns and personal runtime information. Citation authors and the public research repository identity are intentional. No source numerical measurement was evaluated; failed access attempts remain recorded.

The manifest pins the actual public bytes; a publication receipt will be separate. This is a targeted review of the new package, not a new audit of historical artifacts. Existing evidence and the latest actual-results Three.js view are unchanged.
