# Physical-screen proposal status after normalization audit

Updated 2026-10-13, before any experiment or digitization.

## Figure screen: withdrawn before execution

The original `5 < z/l < 6.5` test fails the cross-paper applicability gate. Kiran's geometry is consistent with l being a projected half-side, making the inherited model's far-field threshold z/l = 5√2 ≈ 7.071. No point in the proposed window is inside the model domain under both plausible readings.

See [normalization correction](NORMALIZATION-CORRECTION-2026-10-13.md) for source locations, inspected figures, arithmetic and remaining ambiguity. The [original proposal](PROSPECTIVE-PHYSICS-SCREEN.superseded-2026-10-13.md) is preserved and explicitly superseded. No result, physical falsification claim or experiment ID is assigned.

Do not execute the old window, select whichever mapping favors rejection, or shift the window after inspecting experimental curves. A future figure test needs a new independently frozen protocol and a domain gate robust to every unresolved coordinate mapping and extraction interval. No replacement figure test is launched here.

## Raw static-force screen: deferred

Raw dataset access, reuse conditions and calibration metadata remain unresolved. The prior nine-condition idea remains a candidate, not an executable protocol. Before adopting it, obtain physical rotor coordinates, propeller dimensions, actuation, units, force/moment frames and uncertainty definitions. Treat 32.5 mm as the paper's stated l value; do not assume it is a verified radial arm length. Use measured physical coordinates whenever possible.

No change is made to the frozen source with SHA-256 `6111d7a70a7ca60ed7404889042e4f0ad61c852794289fc6f5e95d67070c9189`. A separately proposed airflow-temporal-sampling study can test numerical error using the same equations, but cannot supply the missing physical validation.
