# Source publication privacy review

Publication scope is the new research package, its synthetic-input rules and references to already public source/literature records. No generated scientific result exists at this source gate.

Reviewed source and documents for credentials, access tokens, private keys, personal contact details, private home/temp/profile paths, pasted user context and original paper/screenshot content. None is included. Browser private process registry/profile arguments are stored outside public evidence; publication records only sanitized launch flags, logical IDs, build/hardware metadata and hashes. Exception paths deliberately omit private details.

Runtime binary/component hashes and generic installation-relative names identify software dependencies; actual binaries and installed package trees are not copied. Public data generated later will be synthetic Boids states and model output, and will receive a separate result privacy review. Source code is original/adapted project code with inherited references and unchanged provenance; no newly obtained third-party dataset or publication figure is redistributed.

No sanitization changes any numerical source, experimental constant, seed or prospective decision rule. Source preparation artifacts are static checks only, not scientific observations. The exact final manifest and commit will be independently fetched before launching science.

The final scan caught private source/runtime/scratch paths in two review documents. They were replaced with repository-relative names or generic role labels before publication. design-reviews/sanitization.json records original-private and actual-public digests; source code, source hashes, scientific values and findings were unchanged. Original reports remain private.
