# Next decision: bound the work we can safely omit

Retain the unchanged F screen as a candidate for the named browser workload. Its 366–396 ms large-case query medians leave a substantial complete-flight budget gap. Do not substitute it retroactively into earlier experiments, claim asymptotic scaling, or treat runtime confirmation as physical validation or novelty.

The next substantive question is: **can bounds computed from the current drone geometry let us omit enough interactions to save substantial time, while providing a sound bound on the resulting modeled load error?** In plain language, we need to know both what work we can skip and how much that can change the answer. A cheap approximation without an honest error bound, or an error check as expensive as the original calculation, does not meet the proposed aim.

The first step is a mathematical and interface desk review, not another benchmark. It must connect conservative geometric bounds to the project's conditional root-defect corollary. That corollary currently assumes complete current coefficients; it does not itself save coefficient construction. It must cover all admission/rejection branches, rounding, orientations, rotor offsets, motor weights and omitted nonnegative contributions. Unsupported or loose cases require exact work or explicit rejection. A failure to establish a useful bound is a legitimate result to preserve.

Any later executable design must compare against both a requalified F-derived baseline and an equally lean exact version of the proposed spatial hierarchy. This separates savings from ordinary spatial organization from any additional value of controlled approximation. Hierarchy construction, admission, bounds, refinement, fallback and load assembly all belong inside its complete-query clock. The prior grid loss is retained as evidence against assuming that fewer candidates imply faster execution.

A crucial fairness condition: the closed Chrome test includes dense diagnostic classification tensors. If the next production-load interface removes those tensors, every timed method must use that same new output contract and earn independent correctness admission. The closed 366–396 ms numbers then provide context, not a matched performance baseline. New development/evaluation families, tolerances, counts, seeds, processes and caps must be declared before scoring. The independent review's suggested thresholds are proposals only; none is adopted or allocated here.
