# Frozen schema and prospective clarifications

Each `inputs/ID.f64` is little-endian binary64, shape [N,17], in historical row order. `inputs/index.json` has `cases` entries `{id,n,t,source,sourceBytes,sourceSha256,path,bytes,sha256}` and a schema description. IDs: `n1000-t20`, `n5000-t20`, `n5000-t60`, `n5000-t180`. Artifact paths are package-relative. Original JSON is hash-verified, decoded and copied only before source freeze; all target admission calculations occur after freeze.

Candidate `results/evidence.json` has `constants:{mg,arm,radius,rho,A,R,c}`, `cases:[case records]`, `complete`, `runtime:{node}`. Each finished case is also written immediately to `results/ID.json`. A caught failure saves `results/failure.json` with current id, progress counters, safe message and completed ids; no replacement case or rerun.

Each case has:
- `id,n,t,inputSha256`.
- `input`: `finite`, `quaternionNormMaxError`, `quaternionBadCount`, `axisNormMaxError`, `axisBadCount`, `offsetNormMaxError`, `offsetDotMaxAbs`, `offsetBadCount`, `nominalZeroCount`, `nominalNegativeCount`, `nominalPositive`, `nominalTotalFinite`, `geometryValid`, `maxTiltDegrees`, `tiltWithin45Count`. Every state is finite (extractor enforces this). Norm means sqrt sum of squares via hypot. Quaternion tolerance is1e-10. Axis norm error, each offset norm error from R, and offset dot axis absolute value all have tolerance1e-9. One offset is bad if either check fails. No normalization. Tilt is acos(clamp(axis_z / norm(axis),-1,1)); 45-degree census is numerical, not an exact-real theorem certificate. Count tilt<=45 with no extra boundary tolerance.
- `admission`: `admitted`, `reasons` (names only), `unsupportedNearCount` (symbol4 terms), `invalidTermCount` (symbol11 terms), `scaledCapMax`, `scaledCapViolationCount`. If any f0<=0 or a nonfinite total, both scaled cap fields are null; geometry census still proceeds. If geometric input invalid, retain census for diagnosis but no solve. Reasons in order: `geometry`, `nominal`, `near-field`, `invalid-term`, `scaled-cap` if applicable.
- `symbols`: `path,bytes,sha256,encoding:'gzip-uint8',shape:[N,N,4],rawBytes,rawSha256`, with self symbol1. `symbolCounts` is length12, all tensor entries counted. Buffer initially ones; center guard violations overwrite all4 entries with11. Remaining eligible centers call the exact pairTerm separately for4 rotors. Symbol0 is never a terminal result.
- `csr`: `offsets,sources,K` artifact objects (`path,bytes,sha256,encoding,shape`). Offsets uint32le shape [4N+1]; sources uint32le shape [M]; K float64le shape [M]. Flattened row4*i+r, ascending source id; retain only strictly positive terms. No a file; reconstruct from K and original f0. M<=2e6.
- `geometryWork`: `directedCenterTests=N*(N-1)`, `centerEligiblePairs`, `centerGuardRejectedPairs`, `pairCalls=4*centerEligiblePairs`, `positiveRotorTerms=M`.
- `graph`: `uniqueVehicleEdges`, `incomingDegree` (N-vector), `maxIncomingDegree`, `heightViolationEdges` (unique j->i with z_j<=z_i), `orderViolationEdges` (rank_j>=rank_i), `descendingEligible`, `order` (height descending, tie id ascending), `dependencyDepth` (N-vector or null), `maxDependencyDepth` (or null). Eligibility uses actual sorted order, independently of45-degree census. Root depth0; depth_i=1+max source depth if nonempty. Every positive rotor term contributes its source to a unique per-receiver source set. No edge file is needed because CSR recovers the complete graph.
- `ordinaryLmax`: max receiver-rotor sum(a)/(4sqrt(2)) if nominal positive/finite, otherwise null. Diagnostic only.
- `solutions`: null unless entire snapshot admitted and order eligible. Otherwise `{direct,picard}`. Direct has `{y,rotors,work,residualMap,residualWork,residualLog,sourceReceiverMismatch}`; Picard has the same plus `{iterates,iterations,converged,lastChange}`. `rotors[i][r]={alpha,x,T}`; returned rotors are the map evaluations that produced y (last Picard update, not its later residual map). `residualMap={y,rotors}` is F(returned y). Source/receiver mismatch is max_i abs(S0_i*y_i^2-sum_r residualMap.rotors[i][r].T)/S0_i. All4 roots per node are counted, including alpha0. Work is `{rootClosures,bisectionIterations,positiveTermMultiplications}`. Picard iterates include initial all-ones. Positive alpha gets exactly56 loop iterations; first convergence test at update1, cap64. Residual maps have separate counts. Norm of residual/change is max absolute log difference.

Reviewer interface: `python source/independent-check.py PACKAGE_PATH OUTPUT_JSON`. Review output contains `pass`, check count, errors and per-case comparison summaries. Checker must retain mismatches rather than epsilon-reclassify. Distinct hyperbolic root formula is used only where solve admitted. No target execution before freeze. Independent vector arithmetic at hard boundaries may yield exact-symbol failures; those remain failures under this contract.

Source and review runners verify pinned bytes against the remotely observed source commit, consume exclusive invocation locks, and enforce180/240-second wall limits. RSS is guarded between receiver rows and solver updates (1.5GiB); output cap256MiB is guarded before each write, symbol gzip64MiB per case. No speed result is inferred from these allocations.

Clarification before freeze: `descendingEligible` is exactly `orderViolationEdges===0`: the saved height-descending/id-ascending order is a topological order. An equal-height positive edge may respect the deterministic tie order; it still counts as a `heightViolationEdges` witness against strict height descent. Such a case would not establish the sufficient theorem's premise but does not invalidate the algebraic ordered solve. Reports must distinguish these two properties. The actual rank check, not tilt or height alone, controls solve eligibility.

Failure retention refinement before freeze: normal artifacts have a255MiB aggregate cap, reserving1MiB of the256MiB total for a compact failure record and partial-evidence index of completed case files. The candidate stores a controlled error phrase or exception class, not arbitrary filesystem exception text. Failure progress includes available geometry/work counters. All direct/map receiver visits also check RSS/time; external supervisor timeout may kill before candidate catch, in which case consumed lock, existing per-case artifacts and supervisor timeout remain evidence.

Prospective diagnostic-serialization convention: a nonfinite scalar diagnostic maximum or bound is encoded as JSON null, consistent with the candidate serializer. The accompanying geometry/nominal/scaled-cap rejection and invalid-count records must retain the cause. The reviewer may match null to an independently nonfinite diagnostic scalar; it must not accept nonfinite sparse coefficients, source amplitudes, roots, rotor loads or residual solutions. A null diagnostic is unavailable evidence, not a numeric zero or admissibility override. This covers overflow in extreme rejected inputs without repairing their state.
