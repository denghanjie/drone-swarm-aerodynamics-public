# Publication check

Only project source, prescribed synthetic state words, measured computational timing, source hashes, reviews and research records belong in this checkpoint. No personal conversation, attachment, credentials, environment-variable dump or experimental participant data is included. Runtime records contain Node version/platform/architecture only. Paths in published prose are repository-relative. Chrome profile and external primary PDFs are not published.

Prepublication checks inspect all newly included text and screenshots; public source manifests pin unchanged model/runtime-facing vendor code and synthetic input. Public verification receipts identify exact full commits. They establish public availability, not peer review or physical validity.
