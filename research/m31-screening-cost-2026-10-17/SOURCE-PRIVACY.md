# Public source privacy review

Scope: this new research package and the already-public ancestry pinned in its source manifest. Publication is authorized for nonsensitive research material. Only generated drone-scene literals, model/algorithm source, prospective protocols, independent reviews, source-reading inventories and executable hashes belong in the source checkpoint.

No private chat transcripts, user attachments, downloaded paper assets, credentials, environment dumps, machine home paths or raw private logs are included. Paths in inventories and manifests are repository-relative. Runtime pins identify executable bytes without publishing private installation paths. Supervision records use command templates; private raw logs stay outside the repository and public copies redact machine/runtime prefixes.

A targeted text scan for home/temp/attachment paths, private-key markers and common access-token patterns is performed before staging. Human/source review also checks the data categories and output scope; a pattern scan alone is not a guarantee. Preserve science failure evidence while applying the same privacy review to later result publication.

The source manifest will bind the reviewed file set. Exact public source verification precedes numerical execution. Source publication makes no claim about numerical success, physical accuracy or novelty.
