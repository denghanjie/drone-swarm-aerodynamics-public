# Evidence schema and comparison contract

Prospective; no execution before reviewed public freeze. Reuses buffered-motion run schema with the explicit changes below. The source and config are authoritative exact serialization/operation definitions; independent review must reconcile them before freeze.

Inputs: the six immutable selected-archive transport parts plus transport/index.json, extract/index.json and previous audited origin/publication. Each decompressed envelope is unchanged `{window,index,record,...}` with `record.body.nativeInput` (64 IDs and17 binary64 words each) and encoded `record.body.native`. Original full line/provenance retained in the pinned input archive; current references point to its window/index. Prior radial diagnostic stages/classes.bin/omitted.bin/witnesses.jsonl and audit bind expected omissions, not new simulated positions.

Output `results/references.json`: one reference entry `{window,index,semantic:{file,bytes,sha256}}` per1920stage. `semantic-<sha>.json` is a sorted-key canonical scientific object plus newline. Recursively convert numeric values to binary64 BE16hex, preserve strings/arrays and signed-zero words, remove only configured rooted paths. It is not a hash-only evidence artifact. Reference and observed normalized bytes deduplicate only after exact byte equality. `witness-<sha>.json` records existing cache state, flat boxes encoded as BE16hex and rows resolved to canonical source IDs; no new computation occurs in witness copying.

`queries.jsonl`: exactly34560rows on success, ordered as protocol. Preserve previous row fields: call,window,rep,method(F/C),index,semantic,referenceSha256,referenceEqual,comparisonMs,inputBeforeSha256,inputAfterSha256,inputPreserved,methodValid,afterInput(nullifpreserved),outerMs,status,reason,cache,witness,excluded,encodePersistMs. NEW fields: baselineReferenceEqual,baselineReferenceSha256,baselineSemanticSha256; nonnull only for F. F checks old nine-exclusion canonical bytes against archived native; the same four additional raw work values are present in excluded, so auditor can reconstruct and check old protection independently without duplicate large CAS files. C has null baseline fields.

Every present excluded field is retained at its full rooted path in `excluded` with its actual value/type. Required work fields cannot be silently absent. Timing/buildPhases are checked structurally as applicable to success/refusal; whole timing objects are administrative. Four added paths are exactly diagnostics.geometryWork.directedCenterTests, diagnostics.geometryWork.certifiedSkippedPairs, diagnostics.screen.actualCenterNormCalls, diagnostics.screen.skippedCenterNormCalls. The original nine exclusions are listed separately as baselineExclusions. No normalization of all geometryWork/screen or scientific diagnostic objects is allowed.

Cache preserves old stats/witness schema structure except witness schema is m31-radial-integration-witness-v1, buildAxisIntervalTests is renamed buildIntervalCoordinateTests, and limits report screenThreshold3,margin2^-20,thresholdSquared and outwardEndpointUlps1. `last` remains action/reason/n/candidateEntries; reuse reason remains all-current-centers-inside-stored-boxes. Each actual build checks all3coordinate intervals per ordered pair, so coordinate-test counter grows by3perbuildpair. Witness rows exclude exactly the pair slots marked by the prior radial mask on matching stages; cache construction and containment must also be independently checked. Data-domain fallback returns null rows (enumerate all) and invalidates cached state, never truncates.

Expected changed work per C call: gathered/orderedPairVisits/componentTests = mask-retained entries; directedCenterTests/actualCenterNormCalls = count of retained slots with priorclass!=0; certifiedSkippedPairs/skippedCenterNormCalls =4032-actualCenterNormCalls. Unchanged logicalPairs,guardRejected,centerEligible,pairCalls,positiveRotorTerms and all scientific fields remain byte-comparison protected. Priorclass and mask words are input evidence, not fabricated model output. Audit derives them independently from the pinned previous diagnostic records plus its passed provenance and checks exact IDs/position/time binding. F actual work must match the original saved baseline, including the four added exclusions.

`groups.jsonl`:108groups (-1..7 ×12), old order/resetMs/sumQueryMs/totalMs/admittedMs/refusedMs/admittedCalls/refusedCalls/ratio schema. Accumulate sums in exact source order, then repetition ratios/median/strict wins as specified. Timing is instrumented same-process native-query cost, not uninstrumented/full-flight throughput. comparisonMs covers only the common thirteen-path comparison; encodePersistMs includes the extra F-only strict comparison and C witness work, but not the row's own append. These asymmetric allocations occur outside primary timing but can influence subsequent GC/cache effects. Summary retains complete,calls,referenceEquality,reps,medianRatio,strictWins,coverage,coverageGate,costGate,keepGate,readEvents,wallSeconds; adds stages1920,runtimeGeneralEquivalenceProvenfalse,performanceMeasuredtrue and explicit conditional scope. Audit must report warmup/measured work totals separately and all18refused replays.

`input-binding.json` binds old extraction index, compressed selectedPin and current source commit/manifest. `environment.json`, `launch.lock`, `exit.json` retain runtime/call/budget closure. Failure.json preserves current method/window/rep/index/nextCall and attempted count; scientific retries forbidden. Audit report must include passed,stages1920,calls34560,filePins for complete results inventory, independently rebuilt summary, baseline strict checks, inherited refusal, input/renderer pins, work totals and explicit limitations. No producer/candidate/scientific imports or model/hypot reruns in audit.
