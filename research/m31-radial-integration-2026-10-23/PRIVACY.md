# Publication scope

Publish synthetic research inputs/derived outputs, implementation and fixed protocols, verified literature references, failures, administrative receipts and own evidence-page screenshots. No user attachments, private chat text, credentials, personal measurements or external-user data enter this checkpoint. Store public paths relative to the repository and sanitize exception roots.

Scan new text/reviews/receipts for private filesystem paths, email addresses and common credential/private-key forms before publication. Inspect both evidence screenshots. Raw input state words and work/force outputs are computational artifacts from previously public material. This is a limited screening procedure, not a universal absence-of-secrets proof. User already authorizes nonsensitive public publication.
