# Source privacy and reuse

Only previously public synthetic inputs and reference records are used. Numerical candidate/kernel/reference/checker copies are byte-identical to the prior source freeze; no model/source-support/root/tolerance/seed change. Supervisor-only edits add phase/error/cleanup-return diagnostics and fail closed if RSS sampling is unavailable. No new personal records, raw environment, credentials, hostnames, serials or private paths are intentionally collected.

The previous failure and both echo-test contexts are retained and linked. No old file or consumed lock is changed. Two new budgets are explicitly declared before target execution. Source reviews and syntax parsing do not evaluate the model. The parent verifies source/dependency pins, publicly commits/pushes them and independently retrieves exact manifest bytes before execution. Result publication still requires its own privacy inspection; this source review cannot anticipate all unexpected logs.

The host path is ordinarily approved tool execution supported by an authorized echo-only test, not a changed security policy or unapproved bypass. It is also not a browser/low-end hardware qualification. Measured model performance remains unknown until the experiment executes and passes its evidence gate.
