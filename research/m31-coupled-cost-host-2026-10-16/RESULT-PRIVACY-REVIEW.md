# Publication privacy and integrity review

This additive package contains previously public synthetic drone states/references (linked, not new personal inputs), newly generated numerical arrays, aggregate runtime hardware metadata, phase timings, source, descriptive analysis and a saved-pose Three.js display. No private attachments, chat records, source-table payload, credentials, personal locations, hostnames, serials, PIDs or private executable paths are included. Node/Python executables are identified by hashes; command records use placeholders. The public Git identity uses the authorized account noreply address.

Candidate/reviewer stdout and stderr are inspected; environment fields are allowlisted in the frozen source. Scientific arrays are untouched. No numeric sanitization, replacement timing or discarded sample occurred. The execution and static-review hash discrepancies remain disclosed. Source references include verified public URLs and stable repository paths. Viewer data are deterministic selections of saved y values, audited timing summaries and prior pose input pins; derive.py documents that transformation. No model execution occurs in display derivation or QA.

Before publication, the coordinator scans all new text for private paths, secrets and identifiers, verifies every result-manifest pin and committed frozen-source pin, and inspects browser screenshots. QA logs must have only local serving URLs and public artifact paths. Screenshots show the research page only. Result manifest excludes itself and publication receipts to avoid circular claims; exact remote verification is published separately after push.
