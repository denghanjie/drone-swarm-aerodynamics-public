# Experiment readiness — no launch authorized

| Gate | Required concrete evidence | Current state |
|---|---|---|
| Compatible acquisition | Identified public release or authorized facility/instrument/airframe with suitable access | Not established |
| Geometry and environment | Rotor layout, coordinate scale, operating point, walls/ambient flow and support mapping | Not established for new acquisition |
| Three signed components | Documented observation of Vx,Vy,Vz at each chosen site, with timing and transforms | Requirement only |
| Calibration and uncertainty | Independent reference, component/cross-talk calibration, covariance, drift/processing history | Not established |
| Physical model amplitude | Independently justified model-to-SI conversion; explicit treatment of inherited empirical gain | Unresolved |
| Feasible signal precision | Instrument-specific uncertainty small enough for a separately justified practical tolerance | Not established |
| Replication and intervals | Precision/pilot justification, run definition, dependence, coverage and multiplicity plan | Unset; no invented counts |
| Execution protocol | Exact files, frozen model/masks/metrics/thresholds, failure rules and resource budget reviewed/published | Not prepared |

Decision: NOT READY FOR PHYSICAL OR NUMERICAL EXECUTION. The design can support a future feasibility/admission discussion. No old scientific/search/display budget is revived. Do not keep rescoring the same exposed field or silently substitute a different aircraft. The next useful trigger is actual facility/instrument information, a genuinely new compatible release or exact calibration provenance. If none becomes available, physical validation remains blocked by missing evidence; that is not proof that the concept is impossible.
