# Result privacy and source preservation

The result package contains synthetic states/poses, simulated model outputs, measured computation durations, source/configuration pins, limited hardware/runtime metadata, review records and local replay QA. It contains no user attachments, private messages, physical experimental data or outside full-text publications.

Scientific output binary types are numerical float64/u32/symbol data with documented shapes. JSON/text files were recursively inspected for private filesystem paths, email addresses and common secret patterns. Public review notes replace private checkout/isolated work paths with generic labels; the numerical results and hashes remain unchanged. The saved arithmetic audit script is published with only its package/output locations changed to command-line arguments and output-directory creation added; its numerical/statistical logic is unchanged. ARITHMETIC.json came from the original path-bound execution. The original script SHA256 is 03b03033298afa81fce8e5f82da600ead1beb80cc243f1977c6e5d8bafbfda82. The frozen independent reviewer is also public and reproducible.

Candidate/reviewer stdout contain compact status JSON only; stderr files are empty. Environment records intentionally identify CPU model, RAM, operating/runtime versions, power mode and load for performance interpretation; they exclude hostname, username, serial, PID and raw environment. Source commit uses the already authorized public GitHub no-reply identity.

QA screenshots show only the local synthetic research viewer. Temporary original QA files remain private; copies are included at the user's request for milestone traces. The screenshots were visually inspected for unintended screen content. No logged-in browser/account content was captured. Original source-manifest pins were verified unchanged after execution; the result manifest includes actual public artifact bytes and renderer dependencies. No scientific result was altered during sanitization.
