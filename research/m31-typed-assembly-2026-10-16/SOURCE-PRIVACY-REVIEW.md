# Source privacy and preparation record

Only new synthetic simulation data and already public model sources are planned. No user attachments, messages, private home paths, credentials, personal records, machine hostname/serial or raw environment dump are included. Hardware model/runtime/power/load observations are deliberately limited performance metadata. Scientific values, seeds, thresholds and budgets are unchanged by sanitization.

Public review/KERNEL-STATIC.md replaces the isolated implementation directory with a generic label and the prior downloaded checkout prefix with its public repository-relative source path. The original note remains in the private isolated review area. review/NUMERICAL-REVIEW-SOURCE.md similarly removes a private working-directory prefix if present. IMPLEMENTATION-MANIFEST.json is the original delivery manifest: README.md maps to review/IMPLEMENTATION.md and its three code files to source/. This mapping changes no file bytes. The new source-manifest pins actual public locations and checksums.

Root source checks: all five JavaScript files parse with the bundled Node parser only; all three Python sources parse via AST only. Ten copied independent NumPy numerical functions have identical ASTs to the pinned old numerical source (constants, rotation, geometry, fade, classifier, hyperbolic root, sparse map, direct solve, input and graph census). No scientific module import, control, target generation, root evaluation or timing occurred during these checks.

Harness fixes before source freeze: rejected-domain persistence tolerates absent scaling/solution and preserves available arrays; full17 inputs are byte-compared after qualification/timed calls outside the query clock; ownership records literal retained and extra-build outputs; final supervisor byte/wall checks run after child exit so a fast exit cannot bypass bounds. These are pre-experiment preparation corrections, not post-outcome protocol changes. The supervisor includes inputs, generation and results in its208MiB aggregate check, including its projected report size, and treats monitor failure as failure.

A recursive source scan found no private absolute paths, email addresses or common credential patterns. Manual source review inspected environment capture, errors, bibliography and public source paths. The runtime may emit unexpected logs; a separate result privacy inspection remains mandatory before public publication. No outside copyrighted source text or physical experimental dataset is redistributed here.

The harness review replaces its private checkout location with [repository].
