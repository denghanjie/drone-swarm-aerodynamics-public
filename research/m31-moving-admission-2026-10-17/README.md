# Can the exact backend follow moving drone states?

This checkpoint tests two recorded64-drone local3D Boids trajectories at0,5,10seconds. The aerodynamic model is queried after flight generation; its forces do not affect the trajectories. Six scheduled states remain the denominator. Read PROTOCOL.md for the prospective gate and later MILESTONE-SUMMARY.md for observed results. The evidence-bound Three.js viewer will replay recorded geometry only. This is an admission test before browser/scale work, not physical validation or a novelty claim.
