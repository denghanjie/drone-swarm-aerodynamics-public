# Candidate/checker interface for source preparation

Draft names and shapes below are to be reconciled by independent source review before freeze. Never execute this preparation package yet.

- `source/config.json`: fixed generation cases (run-a/seed26171001, run-b/seed26171002), count64, duration10, dt0.0025, times[0,5,10], frameEvery0.2, all generator settings; four explicit controls, expected status/branch; source/runtime/resource pins separately. Controls fixed by parent.
- Candidate: `source/run.cjs PACKAGE_ROOT`. One owned permanent `results/kernel-attempt.json`. Supervisor launches once after source/runtime/publication gates. Generation is completed/saved for both cases before any generated-state query, so model admission cannot affect capture. Fixed control method evaluations may precede generation. An unhandled programming exception closes the entire allocation; preserve partial output and missing slots.
- `results/controls/ID.json` and `results/scenes/run-a-t0.json` etc: `{id,kind,input,method}` where kind=control|scheduled, input=`{drones:[{id,state:[17lowercase16hex]}]}`, method=unchanged filtered method complete record. One call per record; no retry, no all-method timing race. Each record pins its source full-state capture through index descriptors. Keep phase callbacks descriptive; do not require all3 on preparation rejection.
- `results/generation/run-a.json` etc: exact generation configuration; copied full17word initial/final; every streamed pose frame `{t,words:[7Nlowercase16hex]}`; all3scheduled slots `{t,status,input,reason}` with status reached|not-reached and null input for missing; any off-schedule terminal full-state diagnostic; saved simulator config/metrics/samples/diagnostics/timing as `runSummary`; source/runtime/config identity. The runner may add declared metadata fields; agree their exact shape before freeze. Keep nonfinite diagnostics explicitly encoded, never null-substitute scientific state. Full scientific inputs must be original captured bits, not decoded from poses.
- `results/index.json`: source/config/runtime identity, constantBits, controls descriptors, generation descriptors, ordered six scheduled descriptors including not-reached, per-file SHA256/bytes, stage completion/error. Exact checker contract must validate closed-set/unique scheduled identity and all input/pose/capture relationships, not trust an arbitrary self-consistent new index.
- `results/check.json`: saved-only independent validation, all control outcomes and each scheduled outcome; denominator6; independent full logical pair statuses and graph diagnosis where resolved; load tolerance/accuracy conditional on admitted states; nontriviality and advance decision. Preserve graph summaries and scientific reference loads in separate `results/reference/ID.json` records as needed.

Fixed scientific helpers copied unchanged from prior cost package; no import/execution during preparation. Independent checker may reuse its exact pair/semantic helpers with disclosed trust, but new ledger/refusal/nontriviality validation must be explicit. Snapshot/candidate agreement is not independent trajectory reproduction. The verifier checks recorded trajectory structure/source/provenance and raw-state identity, not a second generation, continuous-time convergence or physical truth.

Simple fixed corruption controls should be authored independently in the checker contract before source freeze, using fixed small-group witnesses, not hoped-for properties of generated frames. Reject missing witnesses without replacement. Do not make checked model refusal count as numerical failure, nor unchecked unresolved output count as a certified state.
