# Source publication privacy review

Public source contains synthetic configurations, source code, exact file/runtime hashes, repository-relative paths and reviewed research contracts. It excludes private user attachments/conversation text, credentials, account tokens, personal filesystem paths and original literature PDFs. Runtime binaries are not uploaded. Runtime architecture/version/hash are reproducibility metadata, not device serials or hostnames.

Text scan flags the supervisor’s generic /private/var/folders path-redaction pattern; it is a sanitizer rule, not a concrete private path. The public reproduction guide uses placeholder runtime paths. Raw process logs will be kept private; any later public copies must undergo the supervisor’s path redaction and a separate result privacy review. No scientific values are changed by source publication. No new third-party paper assets or citations are introduced.
