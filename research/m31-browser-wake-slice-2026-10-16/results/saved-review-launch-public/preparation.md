# Prospective sole saved-data review preparation

Status: PREPARED, NOT EXECUTED. This package is a new saved-only review under the frozen wake-slice REVIEW-CONTRACT. No old checker is imported, modified or executed. The independent implementation does not copy/import the host's assessment functions and invokes no scientific source. The receiver campaign's old launcher was read as text only to retain its one-attempt supervision pattern.

Bound source freeze: `5862d96e2556d58852f7b1d3a65e00e5303c8061e137f27280041156191c282f`, 82 pins.

The coordinator has confirmed that the sole science attempt is terminal. Preparation may read schema/JSON and hash terminal bytes, but may not decode typed term/state arrays or recalculate scientific quantities. Preparation so far is source authoring, JSON/schema inspection, file hashes, and syntax-only AST parsing. The eventual checker is not invoked by any preparation step. Its exact bytes, input index, arguments, preparation, Python executable and launcher must be approved before the single external launch.

The input index binds all terminal `raw/` files, the core result/budget/stdout/stderr/permanent lock, and the original private scientific-invocation, registry and cleanup bytes. Mutable post-run publication/viewer documents are deliberately not input prerequisites. Frozen source/input pins are independently rechecked during the review. The private input index, invocation and process documents must remain private; published copies may use disclosed path transformations only after the review.

Allowed calculations during the one review are limited to decoding saved IEEE words; finite/range/identity/status/mask/class checks; original-to-packed representation checks; byte transfer comparisons for already stored positions; exact integer sums/differences of saved R/Q/T terms; declared ordinary-sum comparisons; exact epsilon/allowance certificate checks; and saved process/resource/count reconciliation. Approximate display numbers never decide a numerical gate. No quaternion rotation or norm is recomputed, no pair distance, radial coordinate, profile, root, force or shader value is generated, and missing stages are never filled in.

The independent checker reconstructs:

- R's saved-I code and inflow reproduction, exact stored-term sum link to prior I, and ordinary/compensated sum allowances.
- Q's exact policy equality, exact per-term L1 Q−R plus allowance, and exact Q stored-sum gaps.
- Every available control/main raw record's IDs, policy-compatible status/mask/routing, finite scalar envelope, unavailable raw-zero payload and term sign.
- T's exact L1/signed Q−R, T−Q and T−R, exact stored-term sums, positive/qualified counts, stage maxima and deterministic witnesses, and the conservative pre-reduction gate.
- Any available serial result's metadata and exact term-L1-plus-addition gate. The confirmed run stopped before this stage; absence remains explicitly unexecuted and unqualified.
- The frozen/raw input identities, byte accounting, assessment reservations/actuals, scientific callbacks, dispatch/active/padded lanes, API metadata, terminal attempt and private/public cleanup correspondence.

Review computation is bounded by two 80,000-row reference scans, one 80,000-row GPU term scan, one 80,000-row Q/R comparison, 16 control records, at most 16 serial records, fixed prepared-array encoding checks, and the existing 82 source pins plus the terminal input index. Coefficients are exact Python integers using 2^-1074 units; binary32 words are represented in those same units. Saved scalar stage comparisons are arithmetic on existing operands, not geometry reconstruction. All failure examples are bounded to 64 per category; host failure witness caps are separately checked.

`reviewPass` means integrity/faithfulness checks are consistent with the retained evidence. `fullSuiteQualified` requires every R/Q/control/term/serial stage and all numerical gates. A faithful negative result is allowed to have `reviewPass:true`, `fullSuiteQualified:false`, `status:"consistent-recorded-negative"`, `exposureStatus:"partial"`, with serial `present:false`, `complete:false`, `pass:null`. The checker does not hard-code the observed failed rotor as its answer; it derives any failed rows from the saved exact operands. `availableStageQualification` and `exposure` support a viewer that preserves negative evidence.

External supervision: one permanent launcher lock plus one checker lock; no retries or differently named repeats. Total external ceiling 60 seconds; subprocess ceiling at most 59 seconds; checker cooperative ceiling 55 seconds. The launcher captures stdout/stderr, archives exact checker/arguments/input index/preparation/launcher bytes, records exit/time/identity/absence, and limits normal output to 14 MiB within a 16 MiB cap with 2 MiB failure reserve. It checks final process-group absence and reports its own `qualifiedReviewClosure`. A checker report alone does not replace that external closure gate. No browser or additional process is permitted from the checker.

The checker writes one `review.json`; the launcher writes one terminal runtime record. A successful external review closure may return exit 0 even when the scientific result is negative. Any checker exception, integrity disagreement, timeout, output overrun or external cleanup failure is terminal. No edits or rerun are permitted after the reviewer invocation. Unreviewed stages remain unreviewed.
