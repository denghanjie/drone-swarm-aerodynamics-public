# Saved exact-coverage viewer

This page shows the actual two saved64-drone final Boids states, coloured by the new tree-first reference's recorded coverage for one receiver and rotor. The simulation that produced those states used airflow off; this page performs no simulation or aerodynamic query. Positive lines indicate coefficient support, not force magnitude. Boxes bound prepared source centres, not wake volumes. Glyphs are enlarged3times.

The binding pins the numerical index and both tree records. The page checks their exact hashes before enabling the overlay. It derives display membership only from recorded permutation ranges and residual source indices. Invalid selections clear geometry; changed evidence fails closed. The full original flight replay remains linked. All24scene decisions are shown, including deliberate refusals; these refusals can match correctly without being admitted physical states.

The fixed saved-data subset is for display, while the complete24-scene denominator remains in the table. Browser UI work cannot count as scientific numerical validation or performance evidence. Three.js and OrbitControls retain the original vendored versions and license notices.
