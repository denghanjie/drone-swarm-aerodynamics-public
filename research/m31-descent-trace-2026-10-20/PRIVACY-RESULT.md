# Publication privacy scope

New evidence consists of selected synthetic simulation records, exact source identities, derived model descriptors, independent review and screenshots of the local research page. No user attachments, private conversations, credentials or personal location data are included. Both screenshots were inspected for unrelated content. New text is scanned before result freeze for private absolute paths, private-key headers and common token formats. This is a scoped review, not a universal secret-detection guarantee.

No prior raw evidence is copied or modified. The final manifest references unchanged public parts already stored in Git; the new exact-word trace is an additional selected-record artifact with explicit source line hashes and offsets.
