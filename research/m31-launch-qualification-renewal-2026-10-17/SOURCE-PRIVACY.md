# Source privacy and execution scope

Source contains only synthetic inert process fixtures, numeric process-field parsing and saved-evidence checks. No private attachments, chats, account data, credentials, absolute home directories or installation paths are included. A targeted source/review scan found no home/private-temporary prefixes or common credential patterns. The pinned runtime is identified by byte count/hash, supplied by the caller.

Real process inspection requests only numeric pid/ppid/pgid/RSS fields. Only the owned supervisor/guardian observations are saved; unrelated rows and command lines are not published. Synthetic error messages are labeled injected. Any unexpected private path in future raw results must be kept private and handled with separately identified redacted publication derivatives, not silently edited in place.

The planned tool invocation explicitly requests escalated local execution for this harmless qualification. The environment string inside evidence is an attestation, not independent sandbox detection. The actual invocation mode must be recorded after execution, without pretending it was measured by the fixture.
