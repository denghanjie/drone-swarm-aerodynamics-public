# GPU readback checkpoint: no numerical result obtained

**The test stopped in browser process monitoring before it saved GPU output. We have not established GPU readback, drone physics, 5,000-drone performance or novelty.**

We asked a small engineering question: could a known 128-byte integer pattern be computed through WebGPU, copied out and saved exactly? The source and stopping rules were published before the sole trial. The monitor reported an “Unregistered detached descendant” and stopped the owned relay/browser groups. Only a browser-launch-intent event was saved; the host result and actual byte files are absent.

The independent saved-file review failed three of five groups because required evidence was missing. Source identity and output accounting passed. An independent source/read-only audit also found that the monitor's cleanup flag covers known groups; it cannot resolve what happened to the unidentified descendant. A later profile check found no command with the trial's exact browser profile, but cannot settle that uncertainty. A registration timing gap and an actually unadmitted process group remain competing explanations.

This is a failed engineering attempt, not evidence against the aerodynamic idea. Preserve it unchanged. The next browser-monitor question needs a separate study. Scientific reference work can proceed independently; the priority is a small, interpretable physical/numerical comparison rather than adding more recording machinery.
