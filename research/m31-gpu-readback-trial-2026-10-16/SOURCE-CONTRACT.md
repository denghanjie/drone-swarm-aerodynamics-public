## Invocation, bytes and closure

Exactly one browser launch and one `page.evaluate(()=>window.runSyntheticGPUReadback())` are present. Guards and window checks precede the counter; the counter is directly adjacent to the call. The host race is12s, exceeding page cleanup10s; admission also requires enough34s substantive time remaining for that allowance. An evaluate timeout is not cancellation, never triggers retry or another extraction, and marks local observation incomplete. An expired precondition is a host error, not a settled evaluation. Browser/worker clocks are independent.

Observers and routes are installed before navigation/evaluation. Only the pinned HTML/script URLs are fulfilled from local source bytes; all other routes are blocked and counted. Public events use the inherited allowlist, labels and bounds; full private trace stays external. Truncation, dropped callbacks, redirects and unexpected requests disqualify local completeness. Trace closure flags follow actual close returns. A result-file close can only be evidenced by the subsequent worker stdout summary and external capture; result.json does not certify its own final close.

Strict page validation returns an object: ok:false is handled without assuming an exception. Only a fully validated bounded envelope is retained in raw/returned.json. A malformed object yields a safe projection, not arbitrary public strings; independent reviewers cannot reconstruct original malformed content. Checked byteValues are copied into Buffer only after validation. Actual bytes are persisted even for a failed page or expected-content mismatch; no-byte failures retain the envelope only. Expected bytes are used solely for comparison. Every write uses exclusive creation, loops over partial writes, records actual byte counts, preserves partial files on failure and claims close only when close returns. Closing is not a power-loss durability guarantee.

Page phases/device destruction remain self-reported. Browser.close return is recorded separately; it does not prove all owned processes exited. A late or timed-out browser/page operation can outlive a promise race, so external ownership/closure evidence is mandatory. The40s worker timer and34s substantive timer are cooperative JavaScript bounds; parent-owned external limits remain authoritative.

See RESULT-SCHEMA.md for stable artifact names/fields and status precedence. Worker exit0/localObservationComplete can represent a faithfully retained failure and never means GPU success. Independent post-closure reread/comparison and external capture completion remain required; qualified/scientific/historical/performance/independent-proof flags stay false.
