NAVIGATION

1,000 within the tested budget.

The GPU-assisted loop took 0.284 s for one simulated second at 1,000 drones; 1.335 s at 5,000. These short queue tests exclude rendering and airflow.

The code agrees numerically across CPU and GPU. That does not establish real-flight accuracy. Related work already combines many of these ingredients.

The main unanswered question

How much aerodynamic detail is needed to predict swarm passage? We cannot answer that yet. The next essential evidence is a matching measured force-and-moment dataset, followed by multi-drone validation. The existing simulations remain useful as a controlled baseline.
